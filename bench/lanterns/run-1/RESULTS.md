# The pond of a thousand lanterns: run 1, kept with its flaws

Run at commit `afca8f0`. **Its flaws**, corrected for run 2 ([decision 0029](../../../docs/en/decisions/0029-pond-of-lanterns.md), record): Rust was built without WebAssembly SIMD, where the protocol builds it as `bench/garden/rust` is built, with `+simd128`; and the JavaScript heap leaves out the bytes of typed arrays, so the buffers of TypeScript and of the managed module, 27 MiB, are counted nowhere.

Generated by `node scripts/bench-lanterns.mjs`, under the protocol of [decision 0029](../../../docs/en/decisions/0029-pond-of-lanterns.md). Machine: Intel(R) Xeon(R) Processor @ 2.30GHz, 4 cores; Node v24.22.1; Chromium.

## What perasc refused

- **The first Peras version, as written** (`as-written/pond.peras`): 45 errors, E0211 × 35, E0210 × 10; the first: "integer literal where `f64` is expected".
- **The threads** (`threads.peras`): E0241, "this loop cannot run in parallel: it writes an element at another index than its counter's".
- **The shared mesh** (`shared-mesh.peras`): E0204, "`mesh` is used after it was moved".
