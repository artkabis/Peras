# The candle and the garden — results

Generated by `node scripts/candle.mjs` at commit `b2bb68a`, on Intel(R) Xeon(R) Processor @ 2.10GHz. The same zoom into the garden of Apeiron, 40 frames of 200 × 200 pixels from zoom 1 to 64, drawn by three versions that give the same pixels, checked by SHA-256 frame by frame. Every number is also in [results.json](results.json).

| Version | Processor time for the zoom | Against C |
| --- | --: | --: |
| A. TypeScript, as often written | 26684.5 ms | 8.51 × |
| B. TypeScript, by hand | 3317.4 ms | 1.06 × |
| C. Peras | 3137.3 ms | 1.00 × |

A frame's time is the median of 5 rounds, the versions in a new order each round, in Chromium; the zoom's time is the sum of its frames'. What is measured is the processor's time, which drives the energy spent; this machine has no counter of energy, and the animation says what it shows. No memory is reported: the three versions run in one page and share one JavaScript heap, where what one leaves is collected while another runs, so its size belongs to none of them.
