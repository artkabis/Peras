# Peras documentation

English is the reference; every page has a French translation under `docs/fr/` with the same path.

- [Language spec](spec.md): pillars, name and extensions, types, memory model, stack and heap, rasterization, diagnostics, architecture, MVP roadmap.
- [Compiler kickoff plan](kickoff-plan.md): repository layout, technical decisions, quality gates, the first two weeks, working rules.
- `errors/`: one page per compiler error code, shown by `perasc explain <code>`.
- `decisions/`: architecture decisions, with their status and the measurements behind them.
