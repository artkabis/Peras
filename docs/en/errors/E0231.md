# E0231: Generic code that needs endless copies

_French translation: [../../fr/errors/E0231.md](../../fr/errors/E0231.md)._

Each set of type arguments gives a copy of the generic code. Here `nest<T>` calls `nest<Array<T>>`, which calls `nest<Array<Array<T>>>`, and so on: the compiler would never finish. A recursive call, or a field of a generic structure that contains it, must use the same type parameters, or types that do not grow.

## Example

```peras
fn nest<T>(x: sink T, n: i32): i32 {
  if (n == 0) {
    return 0;
  }
  return nest([x], n - 1);
}

export fn start(): i32 {
  return nest(1, 3);
}
```

## Fix

```peras
fn nest<T>(x: sink T, n: i32): i32 {
  if (n == 0) {
    return 0;
  }
  return nest(x, n - 1);
}

export fn start(): i32 {
  return nest(1, 3);
}
```
