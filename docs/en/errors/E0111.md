# E0111: Nesting too deep

_French translation: [../../fr/errors/E0111.md](../../fr/errors/E0111.md)._

Expressions or types are nested more than 128 levels deep. The limit protects the compiler: without it, a hostile or generated file could exhaust its stack and crash it.

## Example

```peras
let x = ((((((((((((((((((… 1 …))))))))))))))))));
```

## Fix

```peras
let inner = …;
let x = inner + 1;
```
