# E0226: An unknown constraint

_French translation: [../../fr/errors/E0226.md](../../fr/errors/E0226.md)._

A constraint says what the types a parameter stands for must be able to do. There are six: `Eq` for `==` and `!=`, `Ord` for comparisons, `Numeric` for arithmetic on integers and floats, `Integer` and `Float` for one kind of number, and `Copy` for values copied instead of moved. Interfaces, coming in the next step of the roadmap, will add your own.

## Example

```peras
fn larger<T: Ordered>(a: T, b: T): T {
  if (a > b) {
    return a;
  }
  return b;
}
```

## Fix

```peras
fn larger<T: Ord>(a: T, b: T): T {
  if (a > b) {
    return a;
  }
  return b;
}
```
