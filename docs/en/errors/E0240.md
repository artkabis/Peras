# E0240: A map's key or a set's element of a type that cannot be one yet

_French translation: [../../fr/errors/E0240.md](../../fr/errors/E0240.md)._

A `Map` finds its keys, and a `Set` its elements, by their hash and their equality, which its runtime knows for integers, booleans and strings ([decision 0005](../decisions/0005-maps-and-sets.md)). A structure, an enumeration or a float needs a rule for both, which comes later: a float, because `NaN` is not equal to itself and `-0` is equal to `+0`.

## Example

```peras
export fn count(): i32 {
  let seen: Map<f64, i32> = Map.new();
  return seen.size;
}
```

## Fix

Use an integer, a boolean or a string as the key:

```peras
export fn count(): i32 {
  let seen: Map<i64, i32> = Map.new();
  return seen.size;
}
```
