# E0219: Missing return

_French translation: [../../fr/errors/E0219.md](../../fr/errors/E0219.md)._

A function with a return type can reach the end of its body without returning a value, for instance when an `if` has no `else`. Every path must end with `return`, or with a loop that never ends (`for (;;)`, `while (true)` without `break`).

## Example

```peras
fn sign(x: i32): i32 {
  if (x < 0) return -1;
  if (x > 0) return 1;
}
```

## Fix

```peras
fn sign(x: i32): i32 {
  if (x < 0) return -1;
  if (x > 0) return 1;
  return 0;
}
```
