# E0224: Unreachable arm

_French translation: [../../fr/errors/E0224.md](../../fr/errors/E0224.md)._

Arms are tried in order, and the first that matches wins. An arm after `_`, after a name that catches everything, or after an arm that already covers the same variant can never run: it is dead code, or the arms are in the wrong order.

## Example

```peras
export fn describe(n: i32): i32 {
  return match (n) {
    _ => 0,
    1 => 10,
  };
}
```

## Fix

```peras
export fn describe(n: i32): i32 {
  return match (n) {
    1 => 10,
    _ => 0,
  };
}
```
