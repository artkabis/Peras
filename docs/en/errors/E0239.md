# E0239: A value a template literal cannot write yet

_French translation: [../../fr/errors/E0239.md](../../fr/errors/E0239.md)._

A template literal, `` `${count} items` ``, writes each of its values as text: a string as it is, a number or a boolean as `toString()` writes it, as JavaScript does. A structure, an array or an option has no text of its own yet: which fields, in which order and how, is for the program to say.

## Example

```peras
struct Point {
  x: f64;
  y: f64;
}

export fn label(p: Point): String {
  return `at ${p}`;
}
```

## Fix

Write its fields there, one value each:

```peras
struct Point {
  x: f64;
  y: f64;
}

export fn label(p: Point): String {
  return `at (${p.x}, ${p.y})`;
}
```
