# E0239: A value a template literal cannot write yet

_French translation: [../../fr/errors/E0239.md](../../fr/errors/E0239.md)._

A template literal, `` `${count} items` ``, writes each of its values as text: a string as it is, an integer or a boolean as `toString()` writes it. Floats, structures and arrays cannot be written yet. Floats as text come next: their shortest exact form, the one JavaScript gives, needs an algorithm of its own.

## Example

```peras
export fn label(price: f64): String {
  return `costs ${price}`;
}
```

## Fix

Write an integer, a boolean or a string there:

```peras
export fn label(cents: i64): String {
  return `costs ${cents} cents`;
}
```
