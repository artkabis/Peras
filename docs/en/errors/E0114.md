# E0114: Invalid assignment target

_French translation: [../../fr/errors/E0114.md](../../fr/errors/E0114.md)._

Something other than a variable, a field or an element is assigned, incremented or decremented: a literal, a call or a calculation.

## Example

```peras
width() = 10;
(a + b)++;
```

## Fix

```peras
size.width = 10;
count++;
```
