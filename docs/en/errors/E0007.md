# E0007: Bidirectional control character

_French translation: [../../fr/errors/E0007.md](../../fr/errors/E0007.md)._

The source contains an invisible Unicode character that changes the display order of text.

These characters (U+202A to U+202E, U+2066 to U+2069) can make code look different from what it compiles to: code that seems commented out runs, and code that seems to run is a comment. This is the [Trojan Source](https://trojansource.codes) attack, CVE-2021-42574. Peras refuses them everywhere, strings and comments included, because a reviewer cannot see them.

## Example

The line below looks like a harmless comment in an editor, but the overrides it contains change what it really is.

```text
/*<U+202E> } <U+2066>if (isAdmin)<U+2069> <U+2066> begin admins only */
```

## Fix

Remove the characters. When text genuinely needs one inside a string, write it as a visible escape:

```peras
let label = "user\u{2067}";
```
