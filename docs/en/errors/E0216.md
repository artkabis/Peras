# E0216: Wrong number of type arguments

_French translation: [../../fr/errors/E0216.md](../../fr/errors/E0216.md)._

`Array` and `Option` take exactly one type argument, and other types take none.

## Example

```peras
let xs: Array = [];
let n: i32<f32> = 1;
```

## Fix

```peras
let xs: Array<f32> = [];
let n: i32 = 1;
```
