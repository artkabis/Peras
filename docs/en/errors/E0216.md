# E0216: Wrong number of type arguments

_French translation: [../../fr/errors/E0216.md](../../fr/errors/E0216.md)._

A type or a function takes as many type arguments as it has type parameters: one for `Array` and `Option`, two for `Result`, the number declared for a [generic](../guide/generics.md) structure, enumeration or function, and none for the other types.

## Example

```peras
let xs: Array = [];
let n: i32<f32> = 1;
```

## Fix

```peras
let xs: Array<f32> = [];
let n: i32 = 1;
```
