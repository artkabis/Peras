# E0209: Moving what is only borrowed

_French translation: [../../fr/errors/E0209.md](../../fr/errors/E0209.md)._

A value is moved by something that does not own it. A parameter that is not `sink` borrows the caller's value; a field belongs to its structure, an element to its array, a module-level value to the module. Move a copy, made with `.copy()`, or declare the parameter `sink`.

## Example

```peras
export fn keep(xs: Array<i32>): Array<i32> {
  return xs;
}
```

## Fix

```peras
export fn keep(xs: sink Array<i32>): Array<i32> {
  return xs;
}
```
