# E0209: Moving what is only borrowed

_French translation: [../../fr/errors/E0209.md](../../fr/errors/E0209.md)._

A value is moved by something that does not own it. A parameter that is not `sink` borrows the caller's value; an element belongs to its array, a module-level value to the module, and a field to its structure, unless the function owns that structure, a variable or a `sink` parameter ([decision 0025](../decisions/0025-moved-fields-and-function-values.md)). Move a copy, made with `.copy()`, or declare the parameter `sink`.

## Example

```peras
export fn keep(xs: Array<i32>): Array<i32> {
  return xs;
}
```

## Fix

```peras
export fn keep(xs: sink Array<i32>): Array<i32> {
  return xs;
}
```
