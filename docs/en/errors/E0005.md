# E0005: Malformed number

_French translation: [../../fr/errors/E0005.md](../../fr/errors/E0005.md)._

A number literal does not follow the number syntax.

Numbers are written in decimal (`42`, `0.5`, `2.5e-4`), hexadecimal (`0xFF`), octal (`0o755`) or binary (`0b1010`). Underscores may separate groups of digits: `1_000_000`. The error explains which rule is broken:

- a prefix with no digits: `0x`;
- a digit outside the base: `0b102`;
- a leading zero: `0755`, which JavaScript once read as octal;
- a misplaced underscore: `1__000`, `1_`;
- an exponent with no digits: `1e`;
- a suffix: `10px`, `5f32`;
- a fraction outside decimal: `0x1.8`.

## Example

```peras
let mode = 0755;
let width = 10px;
```

## Fix

```peras
let mode = 0o755;
let width = 10;
```

For a leading zero, the fix is applied automatically only when the intent is clear: `089` can only be decimal, while `0755` may mean `755` or `0o755`, so you choose. Numbers have no type suffix: annotate the variable instead, `let x: f32 = 5.0`.
