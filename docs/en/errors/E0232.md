# E0232: A type alias that contains itself

_French translation: [../../fr/errors/E0232.md](../../fr/errors/E0232.md)._

A type alias is another name for a type: replacing it by what it names must end. `Tree` below names an array of `Tree`, which names an array of `Tree`, without end. A type that contains itself is a structure or an enumeration, whose size the compiler can compute: an array of them is a buffer on the heap.

## Example

```peras
type Tree = Array<Tree>;

export fn size(t: Tree): i32 {
  return t.length;
}
```

## Fix

```peras
struct Tree {
  children: Array<Tree>;
}

export fn size(t: Tree): i32 {
  return t.children.length;
}
```
