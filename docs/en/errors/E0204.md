# E0204: Value used after a move

_French translation: [../../fr/errors/E0204.md](../../fr/errors/E0204.md)._

A variable is used after its value moved out of it. A value on the heap, an array, a string, or a structure holding one, has a single owner: assigning it, returning it, or passing it to a `sink` parameter moves it, and the old name holds nothing until it is given a new value. A field moved out of a structure, `const c = row.country;`, leaves that field empty, and the structure partly moved: its other fields are still read, but neither the field nor the whole structure is used before the field is given a new value ([decision 0025](../decisions/0025-moved-fields-and-function-values.md)).

## Example

```peras
fn total(xs: sink Array<i32>): i32 {
  return xs.length;
}

export fn twice(): i32 {
  let xs: Array<i32> = [1, 2, 3];
  const first = total(xs);
  return first + total(xs);
}
```

## Fix

```peras
fn total(xs: sink Array<i32>): i32 {
  return xs.length;
}

export fn twice(): i32 {
  let xs: Array<i32> = [1, 2, 3];
  const first = total(xs.copy());
  return first + total(xs);
}
```

In a loop, a value moved in one turn is moved at the start of the next one: give the variable a new value before the turn ends, or leave the loop with `break`.
