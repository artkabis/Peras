# E0112: Const without a value

_French translation: [../../fr/errors/E0112.md](../../fr/errors/E0112.md)._

A `const` is declared without `= value`. A `const` is set once, where it is declared, and never changes.

## Example

```peras
const limit: i32;
```

## Fix

```peras
const limit: i32 = 64;
```
