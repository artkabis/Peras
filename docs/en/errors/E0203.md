# E0203: Unused variable or parameter

_French translation: [../../fr/errors/E0203.md](../../fr/errors/E0203.md)._

A variable or parameter is never read. Assigning a variable is not reading it: a counter that is only incremented is unused too. A parameter that must exist but is not used on purpose, for instance to match a signature, is named with a leading `_`.

## Example

```peras
fn area(width: f64, height: f64): f64 {
  let unused = width * 2.0;
  return width * width;
}
```

## Fix

```peras
fn area(width: f64, _height: f64): f64 {
  return width * width;
}
```
