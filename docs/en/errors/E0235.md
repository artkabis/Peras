# E0235: An implementation that does not match its interface

_French translation: [../../fr/errors/E0235.md](../../fr/errors/E0235.md)._

An `impl Interface for Type` provides exactly the methods the interface declares: generic code that relies on the interface calls each of them, so none may be missing; and a method the interface does not declare belongs in an `impl` of the type itself.

## Example

```peras
interface Shape {
  fn area(self): f64;
  fn perimeter(self): f64;
}

struct Square {
  side: f64;
}

impl Shape for Square {
  fn area(self): f64 {
    return self.side * self.side;
  }

  fn diagonal(self): f64 {
    return self.side * 1.4142;
  }
}
```

## Fix

```peras
interface Shape {
  fn area(self): f64;
  fn perimeter(self): f64;
}

struct Square {
  side: f64;
}

impl Shape for Square {
  fn area(self): f64 {
    return self.side * self.side;
  }

  fn perimeter(self): f64 {
    return 4.0 * self.side;
  }
}

impl Square {
  fn diagonal(self): f64 {
    return self.side * 1.4142;
  }
}
```
