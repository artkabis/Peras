# E0201: Shadowing

_French translation: [../../fr/errors/E0201.md](../../fr/errors/E0201.md)._

A declaration uses the name of another one from an enclosing scope: a parameter, a variable, a function or a structure. Peras refuses shadowing, because with two variables of the same name it is easy to read or modify the wrong one.

## Example

```peras
fn scale(value: f64): f64 {
  if (value > 1.0) {
    let value = 1.0;
    return value;
  }
  return value;
}
```

## Fix

```peras
fn scale(value: f64): f64 {
  if (value > 1.0) {
    let clamped = 1.0;
    return clamped;
  }
  return value;
}
```
