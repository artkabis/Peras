# E0900: Not supported by code generation yet

_French translation: [../../fr/errors/E0900.md](../../fr/errors/E0900.md)._

The program is valid Peras, accepted by every check, but `perasc build` cannot compile one of its constructs yet. Codes `E0900` to `E0999` mark limits of the compiler, not mistakes in the program; they disappear as code generation grows.

Today, code generation handles `i32`, `i64`, `f32`, `f64` and `bool`, structures, enumerations, options, results, strings, maps and sets, and arrays of any of them, with every statement (`for…of` included), calls, `sink` and `inout` parameters, and the methods marked compiled in the [method reference](../reference/methods.md). The other integer types and module-level constants come next; the [status page](../reference/status.md) lists everything.

## Example

```peras
export fn half(x: u8): u8 {
  return x / 2;
}
```

## Fix

Keep such code to `perasc check` for now, or restrict the module compiled with `perasc build` to the supported constructs.

```peras
export fn half(x: i32): i32 {
  return x / 2;
}
```
