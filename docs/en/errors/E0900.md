# E0900: Not supported by code generation yet

_French translation: [../../fr/errors/E0900.md](../../fr/errors/E0900.md)._

The program is valid Peras, accepted by every check, but `perasc build` cannot compile one of its constructs yet. Codes `E0900` to `E0999` mark limits of the compiler, not mistakes in the program; they disappear as code generation grows.

Today, code generation handles functions whose parameters, variables and results are `i32`, `i64`, `f32`, `f64`, `bool`, or structures of these, with arithmetic, comparisons, `if`, `while`, `for`, `break`, `continue`, calls between functions, numeric conversions (`toI32()`, `toI64()`, `toF32()`, `toF64()`), `abs()`, `sqrt()`, `floor()`, `ceil()` and `wrappingAdd()`-style operations. Arrays, strings, options, `for…of`, `inout` parameters and module-level constants come next.

## Example

```peras
export fn total(xs: Array<i32>): i32 {
  return xs.length;
}
```

## Fix

Keep such code to `perasc check` for now, or restrict the module compiled with `perasc build` to the supported constructs.

```peras
export fn total(a: i32, b: i32): i32 {
  return a + b;
}
```
