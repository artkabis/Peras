# E0900: Not supported by code generation yet

_French translation: [../../fr/errors/E0900.md](../../fr/errors/E0900.md)._

The program is valid Peras, accepted by every check, but `perasc build` cannot compile one of its constructs yet. Codes `E0900` to `E0999` mark limits of the compiler, not mistakes in the program; they disappear as code generation grows.

Today, code generation handles `i32`, `i64`, `f32`, `f64` and `bool`, structures, options, and arrays of numbers and booleans, with every statement (`for…of` included), calls, `sink` and, for arrays, `inout` parameters, and the methods marked compiled in the [method reference](../reference/methods.md). Strings, the other integer types, arrays of structures, `inout` on numbers and module-level constants come next; the [status page](../reference/status.md) lists everything.

## Example

```peras
export fn size(name: String): i32 {
  return name.length;
}
```

## Fix

Keep such code to `perasc check` for now, or restrict the module compiled with `perasc build` to the supported constructs.

```peras
export fn size(length: i32): i32 {
  return length;
}
```
