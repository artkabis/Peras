# E0211: Integer literal where a float is expected

_French translation: [../../fr/errors/E0211.md](../../fr/errors/E0211.md)._

An integer literal such as `1` is used where a float is expected. It never becomes a float implicitly: the decimal point makes the intent visible.

## Example

```peras
let gain: f32 = 1;
```

## Fix

```peras
let gain: f32 = 1.0;
```
