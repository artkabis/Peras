# E0211: Integer literal where a float is expected (retired)

_French translation: [../../fr/errors/E0211.md](../../fr/errors/E0211.md)._

**Retired by [decision 0030](../decisions/0030-numeric-literals.md).** An integer literal used where a float is expected is now that float, as in Swift and Go: the lines below build. The code is kept, as every code is, and is no longer issued.

It was issued when an integer literal such as `1` was used where a float was expected, on the reasoning that the decimal point made the intent visible. Decision 0029 measured what it cost: 35 of the 45 errors met writing the pond from its TypeScript.

## Example, which builds today

```peras
let gain: f32 = 1;
```

A variable is still never converted: `n * x`, `n` an `i32` and `x` a float, is refused ([E0210](E0210.md)), with the fix `n.toF64()`.
