# E0116: `for…in` loop

_French translation: [../../fr/errors/E0116.md](../../fr/errors/E0116.md)._

`for…in` comes from JavaScript, where it walks the keys of an object, inherited ones included, as strings. That is rarely what is meant and cannot be checked statically. Peras only has `for…of`, which walks the values of a collection.

## Example

```peras
for (const sample in samples) {
  total += sample;
}
```

## Fix

```peras
for (const sample of samples) {
  total += sample;
}
```
