# E0202: Duplicate declaration

_French translation: [../../fr/errors/E0202.md](../../fr/errors/E0202.md)._

The same name is declared twice in one scope: two variables in a block, two parameters, two fields of a structure, or two declarations of a module (functions, structures and module constants share one namespace).

## Example

```peras
struct Point {
  x: f64;
  x: f64;
}
```

## Fix

```peras
struct Point {
  x: f64;
  y: f64;
}
```
