# E0002: Unterminated string

_French translation: [../../fr/errors/E0002.md](../../fr/errors/E0002.md)._

A string has no closing quote before the end of its line.

A string must close on the line where it starts. Lexing resumes on the next line, so one missing quote gives one error.

## Example

```peras
log("total: );
```

## Fix

Close the string. The suggested fix places the quote before a trailing `;` and its closing brackets.

```peras
log("total: ");
```

To put a line break inside a string, write `\n`: `"line 1\nline 2"`.
