# E0230: An exported generic function

_French translation: [../../fr/errors/E0230.md](../../fr/errors/E0230.md)._

Generic code is compiled once for each set of type arguments the module uses. JavaScript can call an exported function with any value, so there is no single copy to export. Export a function that is not generic, and call the generic one from it with the types you need.

## Example

```peras
export fn larger<T: Ord>(a: T, b: T): T {
  if (a > b) {
    return a;
  }
  return b;
}
```

## Fix

```peras
fn larger<T: Ord>(a: T, b: T): T {
  if (a > b) {
    return a;
  }
  return b;
}

export fn largerInt(a: i32, b: i32): i32 {
  return larger(a, b);
}
```
