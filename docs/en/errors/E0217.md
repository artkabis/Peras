# E0217: Condition is not a bool

_French translation: [../../fr/errors/E0217.md](../../fr/errors/E0217.md)._

The condition of `if`, `while` or `for` is not a `bool`. Peras has no truthiness: `0`, `""` and `None` are not false, and a condition must say what it tests. For numbers, strings and options, the fix writes the comparison.

## Example

```peras
if (count) {
  flush();
}
```

## Fix

```peras
if (count != 0) {
  flush();
}
```
