# E0212: Literal out of range

_French translation: [../../fr/errors/E0212.md](../../fr/errors/E0212.md)._

An integer literal does not fit the type it takes, given by an annotation, a parameter or the other operand. The error shows the bounds of the type.

## Example

```peras
let alpha: u8 = 256;
let big: i32 = 3000000000;
```

## Fix

```peras
let alpha: u8 = 255;
let big: i64 = 3000000000;
```
