# E0244: An import that cannot be made

_French translation: [../../fr/errors/E0244.md](../../fr/errors/E0244.md)._

A managed module imports functions from owned modules (`.peras`) by their relative path, and calls them through checked conversions ([decision 0008](../decisions/0008-managed-mode.md)). The import is refused when the file is not an owned module that compiles, when the name is not an exported function of it, or when the function takes or gives a value that cannot cross yet: numbers, booleans, strings, and arrays, options, results, maps and sets of them cross; a structure or an enumeration is the other module's own type, and does not cross yet.

## Example

With `./stats.peras` exporting `fn mean(xs: Array<f64>): f64`:

```apeiron
import { average } from "./stats.peras";

export fn score(xs: Array<number>): number {
  return average(xs);
}
```

`average` is not a function of `./stats.peras`.

## Fix

Import the function by its name:

```apeiron
import { mean } from "./stats.peras";

export fn score(xs: Array<number>): number {
  return mean(xs);
}
```
