# E0244: An import that cannot be made

_French translation: [../../fr/errors/E0244.md](../../fr/errors/E0244.md)._

A managed module imports functions, structures and enumerations from owned modules (`.peras`) by their relative path, and calls the functions through checked conversions ([decision 0008](../decisions/0008-managed-mode.md), [decision 0021](../decisions/0021-phases-4-and-5.md)). The import is refused when the file is not an owned module that compiles, when the name is not an exported function, structure or enumeration of it, when a function takes or gives a value that cannot cross, or when this module declares a type of the same name as one it imports. Numbers, booleans, strings, the owned module's structures and enumerations that are not generic, and arrays, options, results, maps and sets of them cross; a generic structure, a function or a type of the browser does not.

## Example

With `./stats.peras` exporting `fn mean(xs: Array<f64>): f64`:

```apeiron
import { average } from "./stats.peras";

export fn score(xs: Array<number>): number {
  return average(xs);
}
```

`average` is not a function of `./stats.peras`.

## Fix

Import the function by its name:

```apeiron
import { mean } from "./stats.peras";

export fn score(xs: Array<number>): number {
  return mean(xs);
}
```
