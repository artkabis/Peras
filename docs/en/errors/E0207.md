# E0207: Aliasing with an `inout` argument

_French translation: [../../fr/errors/E0207.md](../../fr/errors/E0207.md)._

Two arguments of a call reach the same place, and one of them is `inout`; or a place passed `inout` is also read elsewhere in the same statement, as in `n += bump(&n)`; or an array changes size while `for…of` goes through it. An `inout` parameter changes its variable in place: anything else reaching it during the call would see it change, or not, depending on the order of evaluation. Two different fields of one structure are different places.

## Example

```peras
fn append(target: inout Array<i32>, source: Array<i32>): void {
  for (const x of source) {
    target.push(x);
  }
}

export fn doubled(): i32 {
  let xs: Array<i32> = [1, 2];
  append(&xs, xs);
  return xs.length;
}
```

## Fix

```peras
fn append(target: inout Array<i32>, source: Array<i32>): void {
  for (const x of source) {
    target.push(x);
  }
}

export fn doubled(): i32 {
  let xs: Array<i32> = [1, 2];
  append(&xs, xs.copy());
  return xs.length;
}
```
