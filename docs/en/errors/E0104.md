# E0104: Unexpected token

_French translation: [../../fr/errors/E0104.md](../../fr/errors/E0104.md)._

A token does not fit the construct being read: a missing `:` before a type, a missing `,` between arguments, or a stray word. The label says what was expected.

## Example

```peras
fn area(width f32): f32 { return width * width; }
```

## Fix

```peras
fn area(width: f32): f32 { return width * width; }
```
