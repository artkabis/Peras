# E0103: Unclosed delimiter

_French translation: [../../fr/errors/E0103.md](../../fr/errors/E0103.md)._

A `(`, `[`, `{` or `<` has no closing counterpart before the statement, the line or the file ends. The error shows where the delimiter was opened and where it should close.

## Example

```peras
let n = max(a, b;
```

## Fix

```peras
let n = max(a, b);
```
