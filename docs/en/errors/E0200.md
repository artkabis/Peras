# E0200: Undefined name

_French translation: [../../fr/errors/E0200.md](../../fr/errors/E0200.md)._

A name is used but not declared in this scope or an enclosing one. When a declared name is close, the fix suggests it.

## Example

```peras
fn total(xs: Array<i32>): i32 {
  let sum = 0;
  for (const x of xs) sum += x;
  return summ;
}
```

## Fix

```peras
fn total(xs: Array<i32>): i32 {
  let sum = 0;
  for (const x of xs) sum += x;
  return sum;
}
```
