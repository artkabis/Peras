# E0223: Unknown variant

_French translation: [../../fr/errors/E0223.md](../../fr/errors/E0223.md)._

An enumeration has the variants its declaration lists, and an option has `None` and `Some`. A variant written with another name, in a value or in a pattern, does not exist.

## Example

```peras
enum Shape {
  Circle(f64),
  Rect(f64, f64),
  Empty,
}

export fn unit(): Shape {
  return Shape.Square(1.0);
}
```

## Fix

```peras
enum Shape {
  Circle(f64),
  Rect(f64, f64),
  Empty,
}

export fn unit(): Shape {
  return Shape.Rect(1.0, 1.0);
}
```
