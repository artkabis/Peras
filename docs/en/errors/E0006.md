# E0006: Strict equality operator

_French translation: [../../fr/errors/E0006.md](../../fr/errors/E0006.md)._

The JavaScript operators `===` and `!==` do not exist in Peras.

Peras never converts types implicitly, so `==` and `!=` already compare strictly, like `===` and `!==` in JavaScript. Comparing values of different types is a type error, not a silent `false`.

## Example

```peras
if (count === 0) { return; }
```

## Fix

```peras
if (count == 0) { return; }
```
