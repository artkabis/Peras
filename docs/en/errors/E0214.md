# E0214: Wrong number of arguments

_French translation: [../../fr/errors/E0214.md](../../fr/errors/E0214.md)._

A function, a structure constructor or a method receives more or fewer arguments than it has parameters. Peras has no optional parameters and no implicit `undefined`.

## Example

```peras
struct Point { x: f64; y: f64; }
const origin = Point(0.0);
```

## Fix

```peras
struct Point { x: f64; y: f64; }
const origin = Point(0.0, 0.0);
```
