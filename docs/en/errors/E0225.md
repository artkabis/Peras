# E0225: `?` in a function that cannot return early

_French translation: [../../fr/errors/E0225.md](../../fr/errors/E0225.md)._

`?` gives the value inside an option or a result, or returns at once what it cannot give: `None` for an option, the error for a result. The function must be able to return that: an `Option` for `?` on an option, a `Result` with the same type of error for `?` on a result. Otherwise, handle the case where it stands, with `match` or `unwrapOr`.

## Example

```peras
fn half(n: i32): Option<i32> {
  if (n % 2 != 0) {
    return None;
  }
  return Some(n / 2);
}

export fn quarter(n: i32): i32 {
  const h = half(n)?;
  return h / 2;
}
```

## Fix

```peras
fn half(n: i32): Option<i32> {
  if (n % 2 != 0) {
    return None;
  }
  return Some(n / 2);
}

export fn quarter(n: i32): Option<i32> {
  const h = half(n)?;
  return Some(h / 2);
}
```
