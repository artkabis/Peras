# E0205: Cannot modify

_French translation: [../../fr/errors/E0205.md](../../fr/errors/E0205.md)._

A `const`, a `for…of` variable declared `const`, or a parameter is modified. A `const` never changes. A parameter is read-only unless it is declared `inout`, which shows every caller that the function modifies it.

## Example

```peras
fn gain(buf: Buffer, factor: f32): void {
  buf.samples[0] = buf.samples[0] * factor;
}
```

## Fix

```peras
fn gain(buf: inout Buffer, factor: f32): void {
  buf.samples[0] = buf.samples[0] * factor;
}
```
