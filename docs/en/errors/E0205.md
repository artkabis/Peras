# E0205: Cannot modify

_French translation: [../../fr/errors/E0205.md](../../fr/errors/E0205.md)._

A `const`, a `for…of` variable declared `const`, or a parameter is modified. A `const` never changes. A parameter is read-only unless it is declared `inout`, which shows every caller that the function modifies it.

## Example

```peras
struct Buffer {
  samples: Array<f32>;
}

fn gain(buf: Buffer, factor: f32): void {
  buf.samples[0] = buf.samples[0] * factor;
}
```

## Fix

```peras
struct Buffer {
  samples: Array<f32>;
}

fn gain(buf: inout Buffer, factor: f32): void {
  buf.samples[0] = buf.samples[0] * factor;
}
```

## A copy of an element

In TypeScript, `const p = ps[i]` names the object the array holds, and changing `p` changes the array. In Peras an element is a value: `const p = ps[i]` reads a copy of it. Declared with `let`, the copy would change and the element would stay as it was, a program that builds and computes something else; so the fix offered here is not `let`, but to write to the element itself ([finding F122](../findings.md)).

```peras error E0205
struct Particle {
  x: f64;
  life: i32;
}

export fn step(): i32 {
  let ps = [Particle(0.0, 2), Particle(1.0, 1)];
  for (let i = 0; i < ps.length; i++) {
    const p = ps[i];
    p.life -= 1;
  }
  return ps[0].life;
}
```

```peras build
struct Particle {
  x: f64;
  life: i32;
}

export fn step(): i32 {
  let ps = [Particle(0.0, 2), Particle(1.0, 1)];
  for (let i = 0; i < ps.length; i++) {
    ps[i].life -= 1;
  }
  return ps[0].life;
}
```

A map's `get` gives a copy too: to change a value held in a map, read it, change it and set it back, `let list = m.get(k).unwrapOr([]); list.push(i); m.set(k, list);`.
