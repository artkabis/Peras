# E0004: Invalid escape sequence

_French translation: [../../fr/errors/E0004.md](../../fr/errors/E0004.md)._

A string contains a `\` followed by something that is not an escape sequence.

Strings accept these escapes only:

| Escape           | Meaning                                         |
| ---------------- | ----------------------------------------------- |
| `\n`, `\r`, `\t` | line feed, carriage return, tab                 |
| `\0`             | null character                                  |
| `\\`, `\'`, `\"` | backslash, quotes                               |
| `\u{1F600}`      | Unicode scalar value, 1 to 6 hexadecimal digits |

The value must lie between `\u{0}` and `\u{10FFFF}`, surrogates `\u{D800}` to `\u{DFFF}` excluded.

## Example

```peras
let pattern = "\d+";
let e = "\u00e9";
```

## Fix

To write a backslash, double it. The JavaScript forms `\u00e9` and `\x41` are written with braces.

```peras
let pattern = "\\d+";
let e = "\u{00e9}";
```
