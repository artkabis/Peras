# E0242: Something only a managed module has

_French translation: [../../fr/errors/E0242.md](../../fr/errors/E0242.md)._

An owned module (`.peras`) compiles to WebAssembly, where nothing waits: it computes and returns. A managed module (`.apeiron`) compiles to JavaScript, for what talks to the browser ([decision 0008](../decisions/0008-managed-mode.md)). Only a managed module may declare an `async` function, `await` a promise, write the types `number` and `Promise<T>`, or `import` functions from another module. Inside a managed module, `await` is also refused outside an `async` function: it waits for a promise, so the function using it must give one itself.

## Example

```peras
export async fn total(xs: Array<f64>): Promise<f64> {
  return xs.reduce((a, x) => a + x, 0.0);
}
```

This is an owned module: it cannot wait.

## Fix

Keep the computation in the owned module, and wait in a `.apeiron` module that imports it:

```peras
export fn total(xs: Array<f64>): f64 {
  return xs.reduce((a, x) => a + x, 0.0);
}
```
