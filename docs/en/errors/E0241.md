# E0241: A loop that cannot run in parallel

_French translation: [../../fr/errors/E0241.md](../../fr/errors/E0241.md)._

The turns of a `parallel for` run on several threads at once, in any order ([decision 0007](../decisions/0007-threads-over-shared-memory.md)). Each turn may read anything the loop does not change, and write only the elements at its own index, `xs[i]`, so that no turn sees another: the results are then those of the loop run in order, bit for bit. A turn may not assign a variable declared outside the loop, read at another index an array the loop writes, call a function, make or release a string, an array or a map, read or write a module variable (each thread has its own copy, [decision 0023](../decisions/0023-module-variables.md)), or leave the loop with `break` or `return`. The loop is written `parallel for (let i = start; i < end; i++)`.

## Example

```peras
export fn smooth(xs: inout Array<f64>): void {
  parallel for (let i = 1; i < xs.length; i++) {
    xs[i] = (xs[i - 1] + xs[i]) / 2.0;
  }
}
```

Each turn reads `xs[i - 1]`, which the turn before writes.

## Fix

Read from one array and write another:

```peras
export fn smooth(xs: Array<f64>, out: inout Array<f64>): void {
  parallel for (let i = 1; i < xs.length; i++) {
    out[i] = (xs[i - 1] + xs[i]) / 2.0;
  }
}
```
