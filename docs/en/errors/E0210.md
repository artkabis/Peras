# E0210: Mismatched types

_French translation: [../../fr/errors/E0210.md](../../fr/errors/E0210.md)._

A value of one type is used where another type is expected. Peras never converts a value implicitly, not even between numbers: `i32 + f64` is an error, because a silent conversion can lose precision or overflow. Between numbers, the fix inserts the explicit conversion, converting toward the float or the wider integer.

## Example

```peras
fn mean(total: f64, count: i32): f64 {
  return total / count;
}
```

## Fix

```peras
fn mean(total: f64, count: i32): f64 {
  return total / count.toF64();
}
```
