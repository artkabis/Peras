# E0234: Methods for a type that cannot have them

_French translation: [../../fr/errors/E0234.md](../../fr/errors/E0234.md)._

An `impl` gives methods to a structure or an enumeration declared in the module. Numbers, strings, arrays and options have the built-in methods of the [method reference](../reference/methods.md); to give one of them your own, wrap it in a structure: it costs nothing, since a structure is kept as its fields.

## Example

```peras
impl f64 {
  fn double(self): f64 {
    return self * 2.0;
  }
}
```

## Fix

```peras
struct Meters {
  value: f64;
}

impl Meters {
  fn double(self): Meters {
    return Meters(self.value * 2.0);
  }
}

export fn twice(m: f64): f64 {
  return Meters(m).double().value;
}
```
