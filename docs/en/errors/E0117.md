# E0117: `break` or `continue` outside a loop

_French translation: [../../fr/errors/E0117.md](../../fr/errors/E0117.md)._

`break` and `continue` only work inside a `for` or `while` loop of the same function.

## Example

```peras
fn check(x: i32): void {
  if (x < 0) {
    break;
  }
}
```

## Fix

```peras
fn check(x: i32): void {
  if (x < 0) {
    return;
  }
}
```
