# E0247: An extern declaration that cannot be kept

_French translation: [../../fr/errors/E0247.md](../../fr/errors/E0247.md)._

An `extern` block declares the JavaScript a managed module calls, with Peras types ([decision 0010](../decisions/0010-calling-javascript.md)). At each call, every value JavaScript gives back is checked against them. Four declarations are refused:

- a resource given to JavaScript, or taken from it: a resource belongs to one variable of Peras, which releases it, and JavaScript would keep it without releasing it;
- a function type anywhere but at the top of a parameter of an `extern` function: there it is a callback, which Peras gives and JavaScript calls; inside another type, or as a result, it would be a function of JavaScript whose values nothing checks;
- `self` of a type the block does not declare: a method belongs to the values JavaScript makes, declared with `type Name;`;
- an `async` function whose result is not a `Promise`.

## Example

```apeiron
extern from "./chart.js" {
  type Chart;
  fn draw(self: String, values: Array<number>): void;
}

export fn one(): i32 {
  return 1;
}
```

`self` is a `String`, which JavaScript does not make as a chart.

## Fix

```apeiron
extern from "./chart.js" {
  type Chart;
  fn draw(self: Chart, values: Array<number>): void;
}

export fn one(): i32 {
  return 1;
}
```
