# E0003: Unterminated block comment

_French translation: [../../fr/errors/E0003.md](../../fr/errors/E0003.md)._

A `/*` comment has no closing `*/`.

A block comment runs until the next `*/`. Without one, the rest of the file is a comment, and the code after it silently disappears.

## Example

```peras
/* compute the gain
fn gain(x: f32): f32 { return x * 2.0; }
```

## Fix

Close the comment where it should end.

```peras
/* compute the gain */
fn gain(x: f32): f32 { return x * 2.0; }
```

Block comments do not nest: the first `*/` closes the comment.
