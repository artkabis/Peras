# E0249: A sort key that is neither a number nor a string

_French translation: [../../fr/errors/E0249.md](../../fr/errors/E0249.md)._

`xs.sortBy((x) => key)` and `xs.sortByDescending((x) => key)` sort an array in place by a key computed once per element. The key is an `i32`, an `i64`, an `f32`, an `f64` (`number`) or a `String`: numbers in the order of `sort()`, `-0` before `+0` and `NaN` last; strings in the order of their Unicode code points, the same in both modes. A structure, an option or a boolean has no order of its own: which field first, in which direction, is for the program to say.

## Example

```peras
struct Order {
  id: i32;
  amount: f64;
}

export fn byOrder(orders: Array<Order>): Array<Order> {
  let sorted = orders.copy();
  sorted.sortBy((o) => o);
  return sorted;
}
```

## Fix

Sort by a field:

```peras
struct Order {
  id: i32;
  amount: f64;
}

export fn byOrder(orders: Array<Order>): Array<Order> {
  let sorted = orders.copy();
  sorted.sortBy((o) => o.amount);
  return sorted;
}
```
