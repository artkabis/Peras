# E0236: A method that does not match its interface

_French translation: [../../fr/errors/E0236.md](../../fr/errors/E0236.md)._

A method of an interface is called on a value of any type that implements it, so it takes `self` first, and each implementation has exactly its parameters, their conventions and its return type, `Self` standing for the type implemented.

## Example

```peras
interface Scale {
  fn scale(inout self, k: f64);
}

struct Circle {
  r: f64;
}

impl Scale for Circle {
  fn scale(self, k: f32): f64 {
    return self.r * k.toF64();
  }
}
```

## Fix

```peras
interface Scale {
  fn scale(inout self, k: f64);
}

struct Circle {
  r: f64;
}

impl Scale for Circle {
  fn scale(inout self, k: f64) {
    self.r *= k;
  }
}
```
