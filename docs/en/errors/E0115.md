# E0115: Condition without parentheses

_French translation: [../../fr/errors/E0115.md](../../fr/errors/E0115.md)._

The condition of `if` or `while` is written without parentheses, as in Rust or Go. Peras keeps the TypeScript syntax, where they are required.

## Example

```peras
if count > 0 {
  log("ready");
}
```

## Fix

```peras
if (count > 0) {
  log("ready");
}
```
