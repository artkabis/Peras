# E0113: Assignment used as an expression

_French translation: [../../fr/errors/E0113.md](../../fr/errors/E0113.md)._

An assignment (`=`, `+=`…) appears where a value is expected. In Peras, an assignment is a statement of its own and has no value, so `if (a = b)`, a classic typo for `==`, cannot compile.

## Example

```peras
let ok = (count = 0);
```

## Fix

```peras
let ok = (count == 0);
```
