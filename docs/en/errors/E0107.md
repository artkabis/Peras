# E0107: Number too large

_French translation: [../../fr/errors/E0107.md](../../fr/errors/E0107.md)._

An integer literal does not fit in 64 bits (above 18446744073709551615), or a float literal is infinite as an `f64` (above about 1.8e308). Whether the value fits the variable's own type, such as `i32`, is checked later by the type checker.

## Example

```peras
let big = 99999999999999999999;
```

## Fix

```peras
let big: u64 = 9999999999999999999;
```
