# E0119: Empty body after `;`

_French translation: [../../fr/errors/E0119.md](../../fr/errors/E0119.md)._

A `;` directly follows `if (…)`, `else`, `while (…)` or `for (…)`. In JavaScript that `;` is the whole body, and the block written after it runs every time. Peras refuses this silent mistake. An intentionally empty body is written `{}`.

## Example

```peras
if (user.isAdmin);
{
  grantAccess();
}
```

## Fix

```peras
if (user.isAdmin) {
  grantAccess();
}
```
