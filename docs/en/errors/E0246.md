# E0246: A property that can only be read

_French translation: [../../fr/errors/E0246.md](../../fr/errors/E0246.md)._

Some properties of the browser are set by the browser itself: an event's `kind` and `key`, a response's `ok` and `status`, a page's `body`. A page reads them, and cannot change them. The [browser reference](../reference/browser.md) says which properties can be assigned.

## Example

```apeiron
export fn rename(e: Event): void {
  e.kind = "click";
}
```

## Fix

Read it into a variable of your own:

```apeiron
export fn label(e: Event): String {
  let text = e.kind;
  text += " event";
  return text;
}
```
