# E0248: A promise never awaited

_French translation: [../../fr/errors/E0248.md](../../fr/errors/E0248.md)._

Calling an `async` function starts its work and gives a promise of its result. Without `await`, the statements after the call run before that work is done, and an error it throws is lost. Forgetting `await` is one of the commonest bugs of asynchronous code; the [web application bugs benchmark](../../../bench/README.md#web-application-bugs-benchweb-bugs) found that TypeScript's linter caught it where Peras did not, until this check ([decision 0011](../decisions/0011-what-to-build-next.md)).

## Example

```apeiron
async fn save(): Promise<void> {
  await sleep(5);
}

export async fn submit(): Promise<String> {
  save();
  return "saved";
}
```

`"saved"` is returned before the save is done.

## Fix

```apeiron
async fn save(): Promise<void> {
  await sleep(5);
}

export async fn submit(): Promise<String> {
  await save();
  return "saved";
}
```

To let the work run on purpose, keep its promise: `const _saving = save();`.
