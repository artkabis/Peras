# E0221: Invalid operator

_French translation: [../../fr/errors/E0221.md](../../fr/errors/E0221.md)._

An operator is applied to a type that does not support it: arithmetic on a `bool`, `-` on an unsigned integer, `!` on a number, `[]` on something other than an array, `?` on something other than an `Option`.

## Example

```peras
fn f(ready: bool, n: i32): bool {
  return !n || ready + 1;
}
```

## Fix

```peras
fn f(ready: bool, n: i32): bool {
  return n == 0 || ready;
}
```
