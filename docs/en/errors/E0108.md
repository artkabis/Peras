# E0108: Chained comparison

_French translation: [../../fr/errors/E0108.md](../../fr/errors/E0108.md)._

Two comparisons are chained, as in `a < b < c`. JavaScript evaluates `a < b` first, then compares that boolean with `c`, which is almost never intended. When both are of the same kind, the fix repeats the middle operand.

## Example

```peras
if (0 < x < 10) { … }
```

## Fix

```peras
if (0 < x && x < 10) { … }
```
