# E0243: Something only an owned module has

_French translation: [../../fr/errors/E0243.md](../../fr/errors/E0243.md)._

A managed module's values belong to the JavaScript garbage collector ([decision 0008](../decisions/0008-managed-mode.md)): nothing moves and nothing is lent. An array, a map, a set or a structure is shared with the caller: an `inout` one can be changed in place, and the caller sees the change. A number, a boolean, a string or an option is copied: an `inout` one could not reach its caller, so it is refused, as is replacing an `inout` parameter with another value. `sink`, which gives a value away, and `parallel for`, which splits a loop between threads over shared memory, belong to owned modules, compiled to WebAssembly.

## Example

```apeiron
export fn bump(n: inout i32): void {
  n += 1;
}
```

## Fix

Return the new value:

```apeiron
export fn bump(n: i32): i32 {
  return n + 1;
}
```
