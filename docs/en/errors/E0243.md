# E0243: Something only an owned module has

_French translation: [../../fr/errors/E0243.md](../../fr/errors/E0243.md)._

A managed module's values belong to the JavaScript garbage collector ([decision 0008](../decisions/0008-managed-mode.md)): nothing moves, nothing is lent, and a parameter is always shared. The conventions `inout` and `sink`, which say who owns a value, and `parallel for`, which splits a loop between threads over shared memory, belong to owned modules, compiled to WebAssembly.

## Example

```apeiron
export fn grow(xs: inout Array<number>): void {
  xs.push(0.0);
}
```

## Fix

Return the new value instead of changing the argument:

```apeiron
export fn grow(xs: Array<number>): Array<number> {
  const out = xs.copy();
  out.push(0.0);
  return out;
}
```
