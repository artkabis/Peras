# E0105: Expected type

_French translation: [../../fr/errors/E0105.md](../../fr/errors/E0105.md)._

A type is missing after `:` in a parameter, a return type or a variable annotation, or inside `<…>`.

## Example

```peras
fn half(x: ): f64 { return x / 2.0; }
```

## Fix

```peras
fn half(x: f64): f64 { return x / 2.0; }
```
