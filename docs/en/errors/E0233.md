# E0233: A module constant computed when the program runs

_French translation: [../../fr/errors/E0233.md](../../fr/errors/E0233.md)._

A module `const` is written into the code wherever it is used, so its value must be known when compiling: literals, other constants, operators, arrays, tuples, structures, options and variants. A call runs only when the program does: compute the value in a function, or write it.

## Example

```peras
fn square(n: i32): i32 {
  return n * n;
}

const AREA: i32 = square(4);

export fn area(): i32 {
  return AREA;
}
```

## Fix

```peras
const SIDE: i32 = 4;
const AREA: i32 = SIDE * SIDE;

export fn area(): i32 {
  return AREA;
}
```
