# E0218: Return value mismatch

_French translation: [../../fr/errors/E0218.md](../../fr/errors/E0218.md)._

`return;` appears in a function that returns a value, or `return value;` in a `void` function. A function returns exactly what its return type says.

## Example

```peras
fn half(x: f64): f64 {
  if (x < 0.0) return;
  return x / 2.0;
}
```

## Fix

```peras
fn half(x: f64): f64 {
  if (x < 0.0) return 0.0;
  return x / 2.0;
}
```
