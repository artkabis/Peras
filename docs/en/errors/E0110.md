# E0110: Expected declaration

_French translation: [../../fr/errors/E0110.md](../../fr/errors/E0110.md)._

The top level of a module only holds declarations: `fn`, `let` and `const`, optionally preceded by `export`, `async` or an attribute such as `@frame`. Statements and expressions go inside a function.

## Example

```peras
log("ready");
```

## Fix

```peras
export fn main(): void {
  log("ready");
}
```
