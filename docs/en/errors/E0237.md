# E0237: An interface used as a type

_French translation: [../../fr/errors/E0237.md](../../fr/errors/E0237.md)._

An interface says what a type can do, not which type a value has. Code that works for every type implementing an interface takes a type parameter constrained by it: it is compiled once per type it is called with, and each call goes straight to that type’s method, with no cost at run time.

## Example

```peras
interface Shape {
  fn area(self): f64;
}

fn double(s: Shape): f64 {
  return s.area() * 2.0;
}
```

## Fix

```peras
interface Shape {
  fn area(self): f64;
}

fn double<T: Shape>(s: T): f64 {
  return s.area() * 2.0;
}
```
