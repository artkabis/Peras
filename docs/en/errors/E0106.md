# E0106: Removed keyword

_French translation: [../../fr/errors/E0106.md](../../fr/errors/E0106.md)._

`var` and `function` come from JavaScript and do not exist in Peras. `var` is scoped to the whole function and can be declared twice; Peras uses `let` and `const`, scoped to their block. Functions are declared with `fn`, which never has a dynamic `this`.

## Example

```peras
function twice(x: i32): i32 {
  var y = x * 2;
  return y;
}
```

## Fix

```peras
fn twice(x: i32): i32 {
  let y = x * 2;
  return y;
}
```
