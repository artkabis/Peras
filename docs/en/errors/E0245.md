# E0245: A resource without an owner

_French translation: [../../fr/errors/E0245.md](../../fr/errors/E0245.md)._

A listener, a timer and a group are resources ([decision 0009](../decisions/0009-browser-and-resources.md)). Each belongs to one variable, and the compiler releases it when that variable goes out of scope: the listener is removed, the timer cleared, the group releases what it holds. Nothing keeps listening or ticking after its owner is gone.

A resource can be given away once: returned from the function, added to a `Group`, or released early with `release()`. After that, its variable holds nothing, and using it is refused. Refused too:

- a resource that nothing keeps, released as soon as it is made;
- a resource given away in a loop, which would be given away more than once;
- a resource kept by an arrow function, a structure, an array, an option or a map, which would have no owner to release it;
- giving away a resource the function only borrowed as a parameter;
- replacing the resource a variable holds.

## Example

```apeiron
export fn watch(button: Element): void {
  button.on("click", (e) => clicked(e));
}

fn clicked(e: Event): void {
  log(e.kind);
}
```

The listener is kept by nothing: it would be removed at once.

## Fix

Return it, so that the caller owns it and releases it when the button goes away:

```apeiron
export fn watch(button: Element): Listener {
  return button.on("click", (e) => clicked(e));
}

fn clicked(e: Event): void {
  log(e.kind);
}
```
