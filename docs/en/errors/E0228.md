# E0228: An operation a type parameter may not support

_French translation: [../../fr/errors/E0228.md](../../fr/errors/E0228.md)._

A generic body is checked once, for every type its parameters may stand for. Without a constraint, a type parameter can be any type, a string or a structure, and `+` does not work on those. The constraint promises that it does; each call is then checked against the promise. The fix inserts the constraint the operation needs.

## Example

```peras
fn sum<T>(xs: Array<T>, start: T): T {
  let total = start;
  for (const x of xs) {
    total = total + x;
  }
  return total;
}
```

## Fix

```peras
fn sum<T: Numeric>(xs: Array<T>, start: T): T {
  let total = start;
  for (const x of xs) {
    total = total + x;
  }
  return total;
}
```
