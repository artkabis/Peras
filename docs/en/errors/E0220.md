# E0220: Missing return type

_French translation: [../../fr/errors/E0220.md](../../fr/errors/E0220.md)._

An exported function, or a function that returns a value, does not declare its return type. Public signatures are always written out, so that a module's interface never depends on what its body happens to return. The fix inserts the type of the returned values.

## Example

```peras
export fn double(x: i32) {
  return x * 2;
}
```

## Fix

```peras
export fn double(x: i32): i32 {
  return x * 2;
}
```
