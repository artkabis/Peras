# E0229: A type argument that nothing determines

_French translation: [../../fr/errors/E0229.md](../../fr/errors/E0229.md)._

The type arguments of a generic function come from its arguments, or from the type the call must have. `empty` takes no argument, and `const xs = empty();` does not say what the array holds: give the variable a type.

## Example

```peras
fn empty<T>(): Array<T> {
  return [];
}

export fn count(): i32 {
  const xs = empty();
  return xs.length;
}
```

## Fix

```peras
fn empty<T>(): Array<T> {
  return [];
}

export fn count(): i32 {
  const xs: Array<i32> = empty();
  return xs.length;
}
```
