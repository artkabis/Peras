# E0101: Missing semicolon

_French translation: [../../fr/errors/E0101.md](../../fr/errors/E0101.md)._

A statement is complete but does not end with `;`. Peras does not insert semicolons: in JavaScript, automatic insertion can silently join two lines, as when a line starts with `(` or `[`.

## Example

```peras
let a = 1
let b = 2;
```

## Fix

```peras
let a = 1;
let b = 2;
```
