# E0001: Invalid character

_French translation: [../../fr/errors/E0001.md](../../fr/errors/E0001.md)._

A character that has no meaning in Peras code appears outside a string or a comment.

Peras code only uses ASCII letters, digits, `_`, whitespace and the operators of the language. Characters pasted from a word processor are a frequent cause: curly quotes, the minus sign `−`, a non-breaking space. Adjacent invalid characters are reported together.

## Example

```peras
let total = price × 2;
let café = 1;
```

## Fix

When the character looks like an ASCII one, the fix replaces it: `×` becomes `*`, `“` becomes `"`, `−` becomes `-`.

```peras
let total = price * 2;
let cafe = 1;
```

Names are ASCII only, which also rules out names that look identical but are spelled with different characters. Text in any language goes in strings: `"café"`. Template literals (`` `…` ``) are not supported yet: join strings with `+`.
