# E0109: Bitwise operator mixed with a comparison

_French translation: [../../fr/errors/E0109.md](../../fr/errors/E0109.md)._

A bitwise operator (`&`, `|`, `^`) and a comparison appear together without parentheses. JavaScript reads `flags & 1 == 0` as `flags & (1 == 0)`, because bitwise operators bind more loosely than comparisons. Peras requires the parentheses, and the fix adds them where they are usually meant.

## Example

```peras
if (flags & 1 == 0) { … }
```

## Fix

```peras
if ((flags & 1) == 0) { … }
```
