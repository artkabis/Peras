# E0008: Source file too large

_French translation: [../../fr/errors/E0008.md](../../fr/errors/E0008.md)._

A source file is 4 GiB or larger.

Positions in the source are 32-bit numbers, which keeps every token and syntax node small. A source file must therefore be smaller than 4 GiB.

## Fix

Split the file into several modules. Large data belongs in a separate file loaded at runtime, not in source code.
