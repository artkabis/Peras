# E0215: Unknown field or method

_French translation: [../../fr/errors/E0215.md](../../fr/errors/E0215.md)._

A field or method does not exist on the type. The fields of a structure come from its declaration; built-in types have a fixed set of members: `length` on arrays and strings, conversions such as `toF64()` and `abs()` on numbers, `sqrt()` or `sin()` on floats, `push()` and `pop()` on arrays, `isSome()` on options.

## Example

```peras
fn size(xs: Array<f32>): i32 {
  return xs.size;
}
```

## Fix

```peras
fn size(xs: Array<f32>): i32 {
  return xs.length;
}
```
