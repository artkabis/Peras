# E0118: Optional marker `?:`

_French translation: [../../fr/errors/E0118.md](../../fr/errors/E0118.md)._

A field or parameter is marked optional with `?:`. Peras has no implicit `undefined` or `null`: a value that may be missing has the type `Option<T>`, holding `Some(value)` or `None`, and the compiler makes you handle both cases.

## Example

```peras
struct User {
  name: String;
  email?: String;
}
```

## Fix

```peras
struct User {
  name: String;
  email: Option<String>;
}
```
