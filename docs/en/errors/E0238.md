# E0238: An arrow function where none can go

_French translation: [../../fr/errors/E0238.md](../../fr/errors/E0238.md)._

An arrow function, `(x) => x * 2`, is compiled in place, as the body of a loop, by the methods of arrays that take one: `map`, `filter`, `reduce`, `find`, `findIndex`, `some` and `every`. In an owned module, it cannot be stored in a variable or passed to a function: those methods need the function itself, written in place, not another value.

In a managed module, an arrow function is also a value ([guide](../guide/managed.md#arrow-functions)): kept in a variable, passed to a function whose parameter has a function type such as `(Event) => void`, and called. Three things are refused there:

- a parameter without its type, `(x) => …`, where nothing gives it: in place, the method or the function called gives it;
- a function type inside another type, `Array<() => void>`: it is written only for a variable, a parameter or a result;
- an exported function that takes or gives a function: JavaScript would call it with functions whose values nothing checks.

## Example

```peras
export fn doubled(xs: Array<i32>): Array<i32> {
  const twice = (x) => x * 2;
  return xs.map(twice);
}
```

## Fix

```peras
export fn doubled(xs: Array<i32>): Array<i32> {
  return xs.map((x) => x * 2);
}
```
