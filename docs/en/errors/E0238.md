# E0238: An arrow function where none can go

_French translation: [../../fr/errors/E0238.md](../../fr/errors/E0238.md)._

An arrow function, `(x) => x * 2`, is compiled in place, as the body of a loop, by the methods of arrays that take one: `map`, `filter`, `reduce`, `find`, `findIndex`, `some` and `every`. It cannot be stored in a variable or passed to a function yet: functions as values come with closures. Those methods also need the function itself, written in place, not another value.

## Example

```peras
export fn doubled(xs: Array<i32>): Array<i32> {
  const twice = (x) => x * 2;
  return xs.map(twice);
}
```

## Fix

```peras
export fn doubled(xs: Array<i32>): Array<i32> {
  return xs.map((x) => x * 2);
}
```
