# E0238: An arrow function where none can go

_French translation: [../../fr/errors/E0238.md](../../fr/errors/E0238.md)._

An arrow function, `(x) => x * 2`, takes the types of its parameters from where it is written: in place, as the argument of `map` and the other methods that take one, or of a function whose parameter has a function type, the method or the function gives them; elsewhere, they are written on it, `(x: i32) => x * 2`. Since [decision 0025](../decisions/0025-moved-fields-and-function-values.md), an arrow function and a function of the module are values in both modes ([guide](../guide/functions.md#functions-as-values)). Two things are refused:

- a parameter without its type, `(x) => …`, where nothing gives it;
- an exported function that takes or gives a function, even inside a structure, an array or an option: JavaScript would call it with functions whose values nothing checks.

## Example

```peras
export fn doubled(xs: Array<i32>): Array<i32> {
  const twice = (x) => x * 2;
  return xs.map(twice);
}
```

## Fix

```peras
export fn doubled(xs: Array<i32>): Array<i32> {
  const twice = (x: i32): i32 => x * 2;
  return xs.map(twice);
}
```
