# E0213: Unknown type

_French translation: [../../fr/errors/E0213.md](../../fr/errors/E0213.md)._

A type name is neither built in nor a structure declared in the module. Built-in types are the integers (`i8` to `i64`, `u8` to `u64`), `f32`, `f64`, `bool`, `String`, `void`, `Array<T>` and `Option<T>`.

## Example

```peras
let ratio: float = 0.5;
let count: number = 1;
```

## Fix

```peras
let ratio: f64 = 0.5;
let count: i32 = 1;
```
