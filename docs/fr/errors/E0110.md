# E0110 : Déclaration attendue

_Version anglaise, qui fait foi : [../../en/errors/E0110.md](../../en/errors/E0110.md)._

Le niveau supérieur d’un module ne contient que des déclarations : `fn`, `struct`, `let` et `const`, éventuellement précédées de `export`, `async` ou d’un attribut comme `@frame`. Les instructions et les expressions vont dans une fonction.

## Exemple

```peras
log("ready");
```

## Correction

```peras
export fn main(): void {
  log("ready");
}
```
