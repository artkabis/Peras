# E0102 : Nom attendu

_Version anglaise, qui fait foi : [../../en/errors/E0102.md](../../en/errors/E0102.md)._

Un nom manque après `fn`, `let`, `const`, `@`, `.` ou dans une liste de paramètres. Un mot-clé ne peut pas servir de nom.

## Exemple

```peras
let match = 1;
```

## Correction

```peras
let match_ = 1;
```
