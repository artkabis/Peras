# E0235 : Une implémentation qui ne correspond pas à son interface

_Version anglaise, qui fait foi : [../../en/errors/E0235.md](../../en/errors/E0235.md)._

Un `impl Interface for Type` fournit exactement les méthodes que l’interface déclare : le code générique qui s’appuie sur l’interface appelle chacune d’elles, aucune ne peut donc manquer ; et une méthode que l’interface ne déclare pas a sa place dans un `impl` du type lui-même.

## Exemple

```peras
interface Shape {
  fn area(self): f64;
  fn perimeter(self): f64;
}

struct Square {
  side: f64;
}

impl Shape for Square {
  fn area(self): f64 {
    return self.side * self.side;
  }

  fn diagonal(self): f64 {
    return self.side * 1.4142;
  }
}
```

## Correction

```peras
interface Shape {
  fn area(self): f64;
  fn perimeter(self): f64;
}

struct Square {
  side: f64;
}

impl Shape for Square {
  fn area(self): f64 {
    return self.side * self.side;
  }

  fn perimeter(self): f64 {
    return 4.0 * self.side;
  }
}

impl Square {
  fn diagonal(self): f64 {
    return self.side * 1.4142;
  }
}
```
