# E0108 : Comparaisons enchaînées

_Version anglaise, qui fait foi : [../../en/errors/E0108.md](../../en/errors/E0108.md)._

Deux comparaisons sont enchaînées, comme dans `a < b < c`. JavaScript évalue d’abord `a < b`, puis compare ce booléen à `c`, ce qui n’est presque jamais voulu. Quand les deux sont de même nature, la correction répète l’opérande du milieu.

## Exemple

```peras
if (0 < x < 10) { … }
```

## Correction

```peras
if (0 < x && x < 10) { … }
```
