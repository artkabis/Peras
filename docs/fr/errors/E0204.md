# E0204 : Valeur utilisée après un déplacement

_Version anglaise, qui fait foi : [../../en/errors/E0204.md](../../en/errors/E0204.md)._

Une variable est utilisée après que sa valeur en est sortie. Une valeur sur le tas, un tableau, une chaîne ou une structure qui en contient, a un seul propriétaire : l’affecter, la renvoyer ou la passer à un paramètre `sink` la déplace, et l’ancien nom ne contient plus rien tant qu’il ne reçoit pas une nouvelle valeur.

## Exemple

```peras
fn total(xs: sink Array<i32>): i32 {
  return xs.length;
}

export fn twice(): i32 {
  let xs: Array<i32> = [1, 2, 3];
  const first = total(xs);
  return first + total(xs);
}
```

## Correction

```peras
fn total(xs: sink Array<i32>): i32 {
  return xs.length;
}

export fn twice(): i32 {
  let xs: Array<i32> = [1, 2, 3];
  const first = total(xs.copy());
  return first + total(xs);
}
```

Dans une boucle, une valeur déplacée pendant un tour l’est encore au début du suivant : donne une nouvelle valeur à la variable avant la fin du tour, ou quitte la boucle avec `break`.
