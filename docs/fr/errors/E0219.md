# E0219 : Retour manquant

_Version anglaise, qui fait foi : [../../en/errors/E0219.md](../../en/errors/E0219.md)._

Une fonction avec un type de retour peut atteindre la fin de son corps sans renvoyer de valeur, par exemple quand un `if` n’a pas de `else`. Chaque chemin doit se terminer par `return`, ou par une boucle qui ne finit jamais (`for (;;)`, `while (true)` sans `break`).

## Exemple

```peras
fn sign(x: i32): i32 {
  if (x < 0) return -1;
  if (x > 0) return 1;
}
```

## Correction

```peras
fn sign(x: i32): i32 {
  if (x < 0) return -1;
  if (x > 0) return 1;
  return 0;
}
```
