# E0238 : Une fonction fléchée là où aucune ne peut aller

_Version anglaise, qui fait foi : [../../en/errors/E0238.md](../../en/errors/E0238.md)._

Une fonction fléchée, `(x) => x * 2`, est compilée sur place, comme le corps d’une boucle, par les méthodes de tableaux qui en prennent une : `map`, `filter`, `reduce`, `find`, `findIndex`, `some` et `every`. Dans un module owned, elle ne peut pas être rangée dans une variable ni passée à une fonction : ces méthodes demandent la fonction elle-même, écrite sur place, pas une autre valeur.

Dans un module managed, une fonction fléchée est aussi une valeur ([guide](../guide/managed.md#fonctions-fléchées)) : gardée dans une variable, passée à une fonction dont le paramètre a un type de fonction comme `(Event) => void`, et appelée. Trois choses y sont refusées :

- un paramètre sans son type, `(x) => …`, là où rien ne le donne : sur place, la méthode ou la fonction appelée le donne ;
- un type de fonction à l’intérieur d’un autre type, `Array<() => void>` : il ne s’écrit que pour une variable, un paramètre ou un résultat ;
- une fonction exportée qui prend ou rend une fonction : JavaScript l’appellerait avec des fonctions dont rien ne vérifie les valeurs.

## Exemple

```peras
export fn doubled(xs: Array<i32>): Array<i32> {
  const twice = (x) => x * 2;
  return xs.map(twice);
}
```

## Correction

```peras
export fn doubled(xs: Array<i32>): Array<i32> {
  return xs.map((x) => x * 2);
}
```
