# E0238 : Une fonction fléchée là où aucune ne peut aller

_Version anglaise, qui fait foi : [../../en/errors/E0238.md](../../en/errors/E0238.md)._

Une fonction fléchée, `(x) => x * 2`, prend les types de ses paramètres de l’endroit où elle est écrite : sur place, comme argument de `map` et des autres méthodes qui en prennent une, ou d’une fonction dont le paramètre a un type fonction, la méthode ou la fonction les donne ; ailleurs, ils s’écrivent sur elle, `(x: i32) => x * 2`. Depuis la [décision 0025](../decisions/0025-moved-fields-and-function-values.md), une fonction fléchée et une fonction du module sont des valeurs dans les deux modes ([guide](../guide/functions.md#les-fonctions-comme-valeurs)). Deux choses sont refusées :

- un paramètre sans son type, `(x) => …`, là où rien ne le donne ;
- une fonction exportée qui prend ou rend une fonction, même dans une structure, un tableau ou une option : JavaScript l’appellerait avec des fonctions dont rien ne vérifie les valeurs.

## Exemple

```peras
export fn doubled(xs: Array<i32>): Array<i32> {
  const twice = (x) => x * 2;
  return xs.map(twice);
}
```

## Correction

```peras
export fn doubled(xs: Array<i32>): Array<i32> {
  const twice = (x: i32): i32 => x * 2;
  return xs.map(twice);
}
```
