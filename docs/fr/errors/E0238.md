# E0238 : Une fonction fléchée là où aucune ne peut aller

_Version anglaise, qui fait foi : [../../en/errors/E0238.md](../../en/errors/E0238.md)._

Une fonction fléchée, `(x) => x * 2`, est compilée sur place, comme le corps d’une boucle, par les méthodes de tableaux qui en prennent une : `map`, `filter`, `reduce`, `find`, `findIndex`, `some` et `every`. Elle ne peut pas encore être rangée dans une variable ni passée à une fonction : les fonctions comme valeurs arriveront avec les fermetures. Ces méthodes demandent aussi la fonction elle-même, écrite sur place, pas une autre valeur.

## Exemple

```peras
export fn doubled(xs: Array<i32>): Array<i32> {
  const twice = (x) => x * 2;
  return xs.map(twice);
}
```

## Correction

```peras
export fn doubled(xs: Array<i32>): Array<i32> {
  return xs.map((x) => x * 2);
}
```
