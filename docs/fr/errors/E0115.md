# E0115 : Condition sans parenthèses

_Version anglaise, qui fait foi : [../../en/errors/E0115.md](../../en/errors/E0115.md)._

La condition d’un `if` ou d’un `while` est écrite sans parenthèses, comme en Rust ou en Go. Peras garde la syntaxe de TypeScript, où elles sont obligatoires.

## Exemple

```peras
if count > 0 {
  log("ready");
}
```

## Correction

```peras
if (count > 0) {
  log("ready");
}
```
