# E0240 : Une clé de table ou un élément d’ensemble d’un type qui ne peut pas encore l’être

_Version anglaise, qui fait foi : [../../en/errors/E0240.md](../../en/errors/E0240.md)._

Une `Map` retrouve ses clés, et un `Set` ses éléments, par leur hachage et leur égalité, que son runtime connaît pour les entiers, les booléens et les chaînes ([décision 0005](../decisions/0005-maps-and-sets.md)). Une structure, une énumération ou un flottant demande une règle pour les deux, qui viendra plus tard : un flottant, parce que `NaN` n’est pas égal à lui-même et que `-0` est égal à `+0`.

## Exemple

```peras
export fn count(): i32 {
  let seen: Map<f64, i32> = Map.new();
  return seen.size;
}
```

## Correction

Utilisez un entier, un booléen ou une chaîne comme clé :

```peras
export fn count(): i32 {
  let seen: Map<i64, i32> = Map.new();
  return seen.size;
}
```
