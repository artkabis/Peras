# E0207 : Alias avec un argument `inout`

_Version anglaise, qui fait foi : [../../en/errors/E0207.md](../../en/errors/E0207.md)._

Deux arguments d’un appel atteignent le même emplacement, et l’un d’eux est `inout` ; ou un emplacement passé `inout` est aussi lu ailleurs dans la même instruction, comme dans `n += bump(&n)` ; ou un tableau change de taille pendant que `for…of` le parcourt. Un paramètre `inout` modifie sa variable sur place : tout ce qui l’atteindrait pendant l’appel la verrait changer, ou non, selon l’ordre d’évaluation. Deux champs différents d’une structure sont deux emplacements différents.

## Exemple

```peras
fn append(target: inout Array<i32>, source: Array<i32>): void {
  for (const x of source) {
    target.push(x);
  }
}

export fn doubled(): i32 {
  let xs: Array<i32> = [1, 2];
  append(&xs, xs);
  return xs.length;
}
```

## Correction

```peras
fn append(target: inout Array<i32>, source: Array<i32>): void {
  for (const x of source) {
    target.push(x);
  }
}

export fn doubled(): i32 {
  let xs: Array<i32> = [1, 2];
  append(&xs, xs.copy());
  return xs.length;
}
```
