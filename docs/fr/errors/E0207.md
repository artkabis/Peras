# E0207 : Alias avec un argument `inout`

_Version anglaise, qui fait foi : [../../en/errors/E0207.md](../../en/errors/E0207.md)._

Deux arguments d’un appel atteignent la même variable, et l’un d’eux est `inout`. Un paramètre `inout` modifie sa variable sur place : un autre argument qui l’atteindrait la verrait changer pendant l’appel.

## Exemple

```peras
fn append(target: inout Array<i32>, source: Array<i32>): void {
  for (const x of source) {
    target.push(x);
  }
}

export fn doubled(): i32 {
  let xs: Array<i32> = [1, 2];
  append(&xs, xs);
  return xs.length;
}
```

## Correction

```peras
fn append(target: inout Array<i32>, source: Array<i32>): void {
  for (const x of source) {
    target.push(x);
  }
}

export fn doubled(): i32 {
  let xs: Array<i32> = [1, 2];
  append(&xs, xs.copy());
  return xs.length;
}
```
