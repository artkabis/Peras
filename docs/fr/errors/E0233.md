# E0233 : Une constante de module calculée à l’exécution

_Version anglaise, qui fait foi : [../../en/errors/E0233.md](../../en/errors/E0233.md)._

Une `const` de module est écrite dans le code partout où elle sert, et un `let` de module d’un module owned est posé avant tout appel ([décision 0023](../decisions/0023-module-variables.md)) : leurs valeurs doivent donc être connues à la compilation, faite de littéraux, d’autres constantes, d’opérateurs, de tableaux, de tuples, de structures, d’options et de variantes. Un appel ne s’exécute que quand le programme tourne : calculez la valeur dans une fonction, ou écrivez-la.

## Exemple

```peras
fn square(n: i32): i32 {
  return n * n;
}

const AREA: i32 = square(4);

export fn area(): i32 {
  return AREA;
}
```

## Correction

```peras
const SIDE: i32 = 4;
const AREA: i32 = SIDE * SIDE;

export fn area(): i32 {
  return AREA;
}
```
