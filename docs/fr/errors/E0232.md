# E0232 : Un alias de type qui se contient lui-même

_Version anglaise, qui fait foi : [../../en/errors/E0232.md](../../en/errors/E0232.md)._

Un alias de type est un autre nom pour un type : le remplacer par ce qu’il nomme doit finir. `Tree` ci-dessous nomme un tableau de `Tree`, qui nomme un tableau de `Tree`, sans fin. Un type qui se contient est une structure ou une énumération, dont le compilateur sait calculer la taille : un tableau d’entre elles est un tampon sur le tas.

## Exemple

```peras
type Tree = Array<Tree>;

export fn size(t: Tree): i32 {
  return t.length;
}
```

## Correction

```peras
struct Tree {
  children: Array<Tree>;
}

export fn size(t: Tree): i32 {
  return t.children.length;
}
```
