# E0227 : Un argument de type qui ne respecte pas une contrainte

_Version anglaise, qui fait foi : [../../en/errors/E0227.md](../../en/errors/E0227.md)._

Une fonction générique fonctionne pour tout type qui respecte les contraintes de ses paramètres, et seulement pour ceux-là : son corps s’appuie dessus. Ici, `larger` compare ses arguments, donc `T` doit être `Ord`, et les chaînes ne sont pas ordonnées. Passez des valeurs dont le type respecte la contrainte.

## Exemple

```peras
fn larger<T: Ord>(a: T, b: T): T {
  if (a > b) {
    return a;
  }
  return b;
}

export fn longest(a: String, b: String): String {
  return larger(a, b);
}
```

## Correction

```peras
fn larger<T: Ord>(a: T, b: T): T {
  if (a > b) {
    return a;
  }
  return b;
}

export fn longest(a: String, b: String): i32 {
  return larger(a.length, b.length);
}
```
