# E0247 : Une déclaration extern qui ne peut pas être gardée

_Version anglaise, qui fait foi : [../../en/errors/E0247.md](../../en/errors/E0247.md)._

Un bloc `extern` déclare le JavaScript qu’appelle un module managed, avec des types Peras ([décision 0010](../decisions/0010-calling-javascript.md)). À chaque appel, chaque valeur que JavaScript rend est vérifiée contre eux. Quatre déclarations sont refusées :

- une ressource donnée à JavaScript, ou reçue de lui : une ressource appartient à une variable de Peras, qui la libère, et JavaScript la garderait sans la libérer ;
- un type fonction ailleurs que comme paramètre d’une fonction `extern` : c’est un rappel, écrit comme une fonction fléchée là où la fonction est appelée, et ailleurs rien ne l’appellerait ;
- un `self` d’un type que le bloc ne déclare pas : une méthode appartient aux valeurs que crée JavaScript, déclarées par `type Nom;` ;
- une fonction `async` dont le résultat n’est pas une `Promise`.

## Exemple

```apeiron
extern from "./chart.js" {
  type Chart;
  fn draw(self: String, values: Array<number>): void;
}

export fn one(): i32 {
  return 1;
}
```

`self` est une `String`, que JavaScript ne crée pas comme un graphique.

## Correction

```apeiron
extern from "./chart.js" {
  type Chart;
  fn draw(self: Chart, values: Array<number>): void;
}

export fn one(): i32 {
  return 1;
}
```
