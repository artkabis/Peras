# E0116 : Boucle `for…in`

_Version anglaise, qui fait foi : [../../en/errors/E0116.md](../../en/errors/E0116.md)._

`for…in` vient de JavaScript, où il parcourt les clés d’un objet, héritées comprises, sous forme de chaînes. C’est rarement ce qui est voulu, et cela ne se vérifie pas statiquement. Peras n’a que `for…of`, qui parcourt les valeurs d’une collection.

## Exemple

```peras
for (const sample in samples) {
  total += sample;
}
```

## Correction

```peras
for (const sample of samples) {
  total += sample;
}
```
