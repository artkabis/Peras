# E0231 : Du code générique qui demande des copies sans fin

_Version anglaise, qui fait foi : [../../en/errors/E0231.md](../../en/errors/E0231.md)._

Chaque jeu d’arguments de type donne une copie du code générique. Ici, `nest<T>` appelle `nest<Array<T>>`, qui appelle `nest<Array<Array<T>>>`, et ainsi de suite : le compilateur ne finirait jamais. Un appel récursif, ou un champ d’une structure générique qui la contient, doit utiliser les mêmes paramètres de type, ou des types qui ne grandissent pas.

## Exemple

```peras
fn nest<T>(x: sink T, n: i32): i32 {
  if (n == 0) {
    return 0;
  }
  return nest([x], n - 1);
}

export fn start(): i32 {
  return nest(1, 3);
}
```

## Correction

```peras
fn nest<T>(x: sink T, n: i32): i32 {
  if (n == 0) {
    return 0;
  }
  return nest(x, n - 1);
}

export fn start(): i32 {
  return nest(1, 3);
}
```
