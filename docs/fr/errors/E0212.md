# E0212 : Littéral hors bornes

_Version anglaise, qui fait foi : [../../en/errors/E0212.md](../../en/errors/E0212.md)._

Un entier littéral ne tient pas dans le type qu’il prend, donné par une annotation, un paramètre ou l’autre opérande. L’erreur indique les bornes du type.

## Exemple

```peras
let alpha: u8 = 256;
let big: i32 = 3000000000;
```

## Correction

```peras
let alpha: u8 = 255;
let big: i64 = 3000000000;
```
