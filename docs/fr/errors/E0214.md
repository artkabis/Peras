# E0214 : Mauvais nombre d’arguments

_Version anglaise, qui fait foi : [../../en/errors/E0214.md](../../en/errors/E0214.md)._

Une fonction, un constructeur de structure ou une méthode reçoit plus ou moins d’arguments qu’elle n’a de paramètres. Peras n’a ni paramètres optionnels ni `undefined` implicite.

## Exemple

```peras
struct Point { x: f64; y: f64; }
const origin = Point(0.0);
```

## Correction

```peras
struct Point { x: f64; y: f64; }
const origin = Point(0.0, 0.0);
```
