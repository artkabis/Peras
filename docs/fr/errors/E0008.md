# E0008 : Fichier source trop volumineux

_Version anglaise, qui fait foi : [../../en/errors/E0008.md](../../en/errors/E0008.md)._

Un fichier source fait 4 Gio ou plus.

Les positions dans le source sont des nombres sur 32 bits, ce qui garde chaque token et chaque nœud de syntaxe compacts. Un fichier source doit donc faire moins de 4 Gio.

## Correction

Découpe le fichier en plusieurs modules. Les grosses données vont dans un fichier séparé chargé à l'exécution, pas dans le code source.
