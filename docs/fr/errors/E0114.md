# E0114 : Cible d’affectation invalide

_Version anglaise, qui fait foi : [../../en/errors/E0114.md](../../en/errors/E0114.md)._

Autre chose qu’une variable, un champ ou un élément est affecté, incrémenté ou décrémenté : un littéral, un appel ou un calcul.

## Exemple

```peras
width() = 10;
(a + b)++;
```

## Correction

```peras
size.width = 10;
count++;
```
