# E0224 : Bras inatteignable

_Version anglaise, qui fait foi : [../../en/errors/E0224.md](../../en/errors/E0224.md)._

Les bras sont essayés dans l’ordre, et le premier qui correspond l’emporte. Un bras après `_`, après un nom qui attrape tout, ou après un bras qui couvre déjà la même variante ne peut jamais s’exécuter : c’est du code mort, ou les bras sont dans le mauvais ordre.

## Exemple

```peras
export fn describe(n: i32): i32 {
  return match (n) {
    _ => 0,
    1 => 10,
  };
}
```

## Correction

```peras
export fn describe(n: i32): i32 {
  return match (n) {
    1 => 10,
    _ => 0,
  };
}
```
