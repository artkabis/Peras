# E0106 : Mot-clé supprimé

_Version anglaise, qui fait foi : [../../en/errors/E0106.md](../../en/errors/E0106.md)._

`var` et `function` viennent de JavaScript et n’existent pas en Peras. `var` porte sur toute la fonction et peut être déclaré deux fois ; Peras utilise `let` et `const`, limités à leur bloc. Les fonctions se déclarent avec `fn`, qui n’a jamais de `this` dynamique.

## Exemple

```peras
function twice(x: i32): i32 {
  var y = x * 2;
  return y;
}
```

## Correction

```peras
fn twice(x: i32): i32 {
  let y = x * 2;
  return y;
}
```
