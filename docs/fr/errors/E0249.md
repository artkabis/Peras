# E0249 : Une clé de tri qui n’est ni un nombre ni une chaîne

_Version anglaise, qui fait foi : [../../en/errors/E0249.md](../../en/errors/E0249.md)._

`xs.sortBy((x) => clé)` et `xs.sortByDescending((x) => clé)` trient un tableau sur place par une clé calculée une fois par élément. La clé est un `i32`, un `i64`, un `f32`, un `f64` (`number`) ou une `String` : les nombres dans l’ordre de `sort()`, `-0` avant `+0` et `NaN` en dernier ; les chaînes dans l’ordre de leurs points de code Unicode, le même dans les deux modes. Une structure, une option ou un booléen n’a pas d’ordre propre : quel champ d’abord, dans quel sens, c’est au programme de le dire.

## Exemple

```peras
struct Order {
  id: i32;
  amount: f64;
}

export fn byOrder(orders: Array<Order>): Array<Order> {
  let sorted = orders.copy();
  sorted.sortBy((o) => o);
  return sorted;
}
```

## Correction

Triez par un champ :

```peras
struct Order {
  id: i32;
  amount: f64;
}

export fn byOrder(orders: Array<Order>): Array<Order> {
  let sorted = orders.copy();
  sorted.sortBy((o) => o.amount);
  return sorted;
}
```
