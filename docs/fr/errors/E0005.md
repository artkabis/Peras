# E0005 : Nombre mal formé

_Version anglaise, qui fait foi : [../../en/errors/E0005.md](../../en/errors/E0005.md)._

Un nombre littéral ne respecte pas la syntaxe des nombres.

Les nombres s'écrivent en décimal (`42`, `0.5`, `2.5e-4`), en hexadécimal (`0xFF`), en octal (`0o755`) ou en binaire (`0b1010`). Des tirets bas peuvent séparer des groupes de chiffres : `1_000_000`. L'erreur indique la règle enfreinte :

- un préfixe sans chiffre : `0x` ;
- un chiffre hors de la base : `0b102` ;
- un zéro en tête : `0755`, que JavaScript lisait autrefois en octal ;
- un tiret bas mal placé : `1__000`, `1_` ;
- un exposant sans chiffre : `1e` ;
- un suffixe : `10px`, `5f32` ;
- une partie fractionnaire hors décimal : `0x1.8`.

## Exemple

```peras
let mode = 0755;
let width = 10px;
```

## Correction

```peras
let mode = 0o755;
let width = 10;
```

Pour un zéro en tête, la correction n'est appliquée automatiquement que si l'intention est claire : `089` ne peut être que décimal, alors que `0755` peut signifier `755` ou `0o755`, c'est donc à toi de choisir. Les nombres n'ont pas de suffixe de type : annote plutôt la variable, `let x: f32 = 5.0`.
