# E0113 : Affectation utilisée comme expression

_Version anglaise, qui fait foi : [../../en/errors/E0113.md](../../en/errors/E0113.md)._

Une affectation (`=`, `+=`…) apparaît là où une valeur est attendue. En Peras, une affectation est une instruction à part entière et n’a pas de valeur : `if (a = b)`, faute de frappe classique pour `==`, ne peut donc pas compiler.

## Exemple

```peras
let ok = (count = 0);
```

## Correction

```peras
let ok = (count == 0);
```
