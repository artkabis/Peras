# E0103 : Délimiteur non fermé

_Version anglaise, qui fait foi : [../../en/errors/E0103.md](../../en/errors/E0103.md)._

Un `(`, `[`, `{` ou `<` n’a pas de fermeture avant la fin de l’instruction, de la ligne ou du fichier. L’erreur montre où le délimiteur a été ouvert et où il devrait se fermer.

## Exemple

```peras
let n = max(a, b;
```

## Correction

```peras
let n = max(a, b);
```
