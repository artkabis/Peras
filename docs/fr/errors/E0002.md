# E0002 : Chaîne non terminée

_Version anglaise, qui fait foi : [../../en/errors/E0002.md](../../en/errors/E0002.md)._

Une chaîne n'a pas de guillemet fermant avant la fin de sa ligne.

Une chaîne doit se fermer sur la ligne où elle commence. L'analyse reprend à la ligne suivante : un guillemet manquant donne une seule erreur.

## Exemple

```peras
log("total: );
```

## Correction

Ferme la chaîne. La correction proposée place le guillemet avant un `;` final et ses parenthèses fermantes.

```peras
log("total: ");
```

Pour mettre un retour à la ligne dans une chaîne, écris `\n` : `"ligne 1\nligne 2"`.
