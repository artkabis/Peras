# E0243 : Ce que seul un module owned possède

_Version anglaise, qui fait foi : [../../en/errors/E0243.md](../../en/errors/E0243.md)._

Les valeurs d’un module managed appartiennent au ramasse-miettes de JavaScript ([décision 0008](../decisions/0008-managed-mode.md)) : rien n’est déplacé, rien n’est prêté. Un tableau, une table, un ensemble ou une structure est partagé avec l’appelant : un `inout` peut être changé sur place, et l’appelant voit le changement. Un nombre, un booléen, une chaîne ou une option est copié : un `inout` ne pourrait pas atteindre son appelant, il est donc refusé, comme le fait de remplacer un paramètre `inout` par une autre valeur. `sink`, qui donne une valeur, et `parallel for`, qui partage une boucle entre fils sur une mémoire commune, appartiennent aux modules owned, compilés en WebAssembly.

## Exemple

```apeiron
export fn bump(n: inout i32): void {
  n += 1;
}
```

## Correction

Rendez la nouvelle valeur :

```apeiron
export fn bump(n: i32): i32 {
  return n + 1;
}
```
