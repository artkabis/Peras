# E0243 : Ce que seul un module owned possède

_Version anglaise, qui fait foi : [../../en/errors/E0243.md](../../en/errors/E0243.md)._

Les valeurs d’un module managed appartiennent au ramasse-miettes de JavaScript ([décision 0008](../decisions/0008-managed-mode.md)) : rien n’est déplacé, rien n’est prêté, et un paramètre est toujours partagé. Les conventions `inout` et `sink`, qui disent à qui appartient une valeur, et `parallel for`, qui partage une boucle entre fils sur une mémoire commune, appartiennent aux modules owned, compilés en WebAssembly.

## Exemple

```apeiron
export fn grow(xs: inout Array<number>): void {
  xs.push(0.0);
}
```

## Correction

Rendez la nouvelle valeur au lieu de changer l’argument :

```apeiron
export fn grow(xs: Array<number>): Array<number> {
  const out = xs.copy();
  out.push(0.0);
  return out;
}
```
