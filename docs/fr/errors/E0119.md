# E0119 : Corps vide après `;`

_Version anglaise, qui fait foi : [../../en/errors/E0119.md](../../en/errors/E0119.md)._

Un `;` suit directement `if (…)`, `else`, `while (…)` ou `for (…)`. En JavaScript, ce `;` est tout le corps, et le bloc écrit après s’exécute à chaque fois. Peras refuse cette erreur silencieuse. Un corps volontairement vide s’écrit `{}`.

## Exemple

```peras
if (user.isAdmin);
{
  grantAccess();
}
```

## Correction

```peras
if (user.isAdmin) {
  grantAccess();
}
```
