# E0100 : Expression attendue

_Version anglaise, qui fait foi : [../../en/errors/E0100.md](../../en/errors/E0100.md)._

Une valeur manque là où la grammaire en attend une : après `=`, après un opérateur, entre parenthèses ou comme argument.

## Exemple

```peras
let total = price * ;
```

## Correction

```peras
let total = price * quantity;
```
