# E0105 : Type attendu

_Version anglaise, qui fait foi : [../../en/errors/E0105.md](../../en/errors/E0105.md)._

Un type manque après `:` dans un paramètre, un type de retour ou une annotation de variable, ou entre `<…>`.

## Exemple

```peras
fn half(x: ): f64 { return x / 2.0; }
```

## Correction

```peras
fn half(x: f64): f64 { return x / 2.0; }
```
