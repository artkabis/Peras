# E0236 : Une méthode qui ne correspond pas à son interface

_Version anglaise, qui fait foi : [../../en/errors/E0236.md](../../en/errors/E0236.md)._

Une méthode d’interface est appelée sur une valeur de n’importe quel type qui l’implémente : elle prend donc `self` en premier, et chaque implémentation a exactement ses paramètres, leurs conventions et son type de retour, `Self` représentant le type implémenté.

## Exemple

```peras
interface Scale {
  fn scale(inout self, k: f64);
}

struct Circle {
  r: f64;
}

impl Scale for Circle {
  fn scale(self, k: f32): f64 {
    return self.r * k.toF64();
  }
}
```

## Correction

```peras
interface Scale {
  fn scale(inout self, k: f64);
}

struct Circle {
  r: f64;
}

impl Scale for Circle {
  fn scale(inout self, k: f64) {
    self.r *= k;
  }
}
```
