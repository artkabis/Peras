# E0245 : Une ressource sans propriétaire

_Version anglaise, qui fait foi : [../../en/errors/E0245.md](../../en/errors/E0245.md)._

Un écouteur, un minuteur et un groupe sont des ressources ([décision 0009](../decisions/0009-browser-and-resources.md)). Chacun appartient à une variable, et le compilateur le libère quand cette variable sort de sa portée : l’écouteur est retiré, le minuteur arrêté, le groupe libère ce qu’il tient. Rien ne continue d’écouter ou de battre une fois son propriétaire parti.

Une ressource peut être donnée une fois : rendue par la fonction, ajoutée à un `Group`, ou libérée plus tôt par `release()`. Ensuite, sa variable ne tient plus rien, et l’utiliser est refusé. Sont refusés aussi :

- une ressource que rien ne garde, libérée dès sa création ;
- une ressource donnée dans une boucle, qui serait donnée plus d’une fois ;
- une ressource gardée par une fonction fléchée, une structure, un tableau, une option ou une table, qui n’aurait pas de propriétaire pour la libérer ;
- donner une ressource que la fonction ne fait qu’emprunter en paramètre.

Remplacer la ressource d’une variable `let` est permis, et libère celle qu’elle tenait. Une fonction fléchée qui doit remplacer une ressource, comme une recherche qui attend que l’utilisateur ait fini de taper, la garde dans un `Slot` d’un groupe, `group.slot()`, qu’elle peut utiliser ([référence du navigateur](../reference/browser.md)).

## Exemple

```apeiron
export fn watch(button: Element): void {
  button.on("click", (e) => clicked(e));
}

fn clicked(e: Event): void {
  log(e.kind);
}
```

L’écouteur n’est gardé par rien : il serait retiré aussitôt.

## Correction

Rendez-le, pour que l’appelant le possède et le libère quand le bouton disparaît :

```apeiron
export fn watch(button: Element): Listener {
  return button.on("click", (e) => clicked(e));
}

fn clicked(e: Event): void {
  log(e.kind);
}
```
