# E0223 : Variante inconnue

_Version anglaise, qui fait foi : [../../en/errors/E0223.md](../../en/errors/E0223.md)._

Une énumération a les variantes que liste sa déclaration, et une option a `None` et `Some`. Une variante écrite sous un autre nom, dans une valeur ou dans un motif, n’existe pas.

## Exemple

```peras
enum Shape {
  Circle(f64),
  Rect(f64, f64),
  Empty,
}

export fn unit(): Shape {
  return Shape.Square(1.0);
}
```

## Correction

```peras
enum Shape {
  Circle(f64),
  Rect(f64, f64),
  Empty,
}

export fn unit(): Shape {
  return Shape.Rect(1.0, 1.0);
}
```
