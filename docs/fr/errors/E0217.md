# E0217 : La condition n’est pas un bool

_Version anglaise, qui fait foi : [../../en/errors/E0217.md](../../en/errors/E0217.md)._

La condition d’un `if`, d’un `while` ou d’un `for` n’est pas un `bool`. Peras n’a pas de « truthiness » : `0`, `""` et `None` ne valent pas faux, et une condition doit dire ce qu’elle teste. Pour les nombres, les chaînes et les options, la correction écrit la comparaison.

## Exemple

```peras
if (count) {
  flush();
}
```

## Correction

```peras
if (count != 0) {
  flush();
}
```
