# E0228 : Une opération qu’un paramètre de type peut ne pas permettre

_Version anglaise, qui fait foi : [../../en/errors/E0228.md](../../en/errors/E0228.md)._

Un corps générique est vérifié une fois, pour tous les types que ses paramètres peuvent représenter. Sans contrainte, un paramètre de type peut être n’importe quel type, une chaîne ou une structure, et `+` ne marche pas sur ceux-là. La contrainte promet que si ; chaque appel est ensuite vérifié par rapport à cette promesse. La correction insère la contrainte dont l’opération a besoin.

## Exemple

```peras
fn sum<T>(xs: Array<T>, start: T): T {
  let total = start;
  for (const x of xs) {
    total = total + x;
  }
  return total;
}
```

## Correction

```peras
fn sum<T: Numeric>(xs: Array<T>, start: T): T {
  let total = start;
  for (const x of xs) {
    total = total + x;
  }
  return total;
}
```
