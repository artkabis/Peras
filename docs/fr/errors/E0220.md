# E0220 : Type de retour manquant

_Version anglaise, qui fait foi : [../../en/errors/E0220.md](../../en/errors/E0220.md)._

Une fonction exportée, ou une fonction qui renvoie une valeur, ne déclare pas son type de retour. Les signatures publiques sont toujours écrites, pour que l’interface d’un module ne dépende jamais de ce que son corps renvoie. La correction insère le type des valeurs renvoyées.

## Exemple

```peras
export fn double(x: i32) {
  return x * 2;
}
```

## Correction

```peras
export fn double(x: i32): i32 {
  return x * 2;
}
```
