# E0107 : Nombre trop grand

_Version anglaise, qui fait foi : [../../en/errors/E0107.md](../../en/errors/E0107.md)._

Un entier littéral ne tient pas sur 64 bits (au-delà de 18446744073709551615), ou un flottant littéral est infini en `f64` (au-delà d’environ 1.8e308). Le type checker vérifie ensuite que la valeur tient dans le type de la variable, comme `i32`.

## Exemple

```peras
let big = 99999999999999999999;
```

## Correction

```peras
let big: u64 = 9999999999999999999;
```
