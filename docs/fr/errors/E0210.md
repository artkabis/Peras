# E0210 : Types incompatibles

_Version anglaise, qui fait foi : [../../en/errors/E0210.md](../../en/errors/E0210.md)._

Une valeur d’un type est utilisée là où un autre type est attendu. Peras ne convertit jamais une valeur implicitement, pas même entre nombres : `i32 + f64` est une erreur, car une conversion silencieuse peut perdre de la précision ou déborder. Entre nombres, la correction insère la conversion explicite, vers le flottant ou vers l’entier le plus large.

## Exemple

```peras
fn mean(total: f64, count: i32): f64 {
  return total / count;
}
```

## Correction

```peras
fn mean(total: f64, count: i32): f64 {
  return total / count.toF64();
}
```
