# E0241 : Une boucle qui ne peut pas tourner en parallèle

_Version anglaise, qui fait foi : [../../en/errors/E0241.md](../../en/errors/E0241.md)._

Les tours d’une `parallel for` tournent sur plusieurs fils à la fois, dans n’importe quel ordre ([décision 0007](../decisions/0007-threads-over-shared-memory.md)). Chaque tour peut lire tout ce que la boucle ne change pas, et n’écrire que les éléments à son propre indice, `xs[i]`, pour qu’aucun tour n’en voie un autre : les résultats sont alors ceux de la boucle exécutée dans l’ordre, bit pour bit. Un tour ne peut pas affecter une variable déclarée hors de la boucle, lire à un autre indice un tableau que la boucle écrit, appeler une fonction, créer ou libérer une chaîne, un tableau ou une table, ni sortir de la boucle par `break` ou `return`. La boucle s’écrit `parallel for (let i = début; i < fin; i++)`.

## Exemple

```peras
export fn smooth(xs: inout Array<f64>): void {
  parallel for (let i = 1; i < xs.length; i++) {
    xs[i] = (xs[i - 1] + xs[i]) / 2.0;
  }
}
```

Chaque tour lit `xs[i - 1]`, que le tour d’avant écrit.

## Correction

Lire un tableau et en écrire un autre :

```peras
export fn smooth(xs: Array<f64>, out: inout Array<f64>): void {
  parallel for (let i = 1; i < xs.length; i++) {
    out[i] = (xs[i - 1] + xs[i]) / 2.0;
  }
}
```
