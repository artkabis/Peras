# E0242 : Ce que seul un module managed possède

_Version anglaise, qui fait foi : [../../en/errors/E0242.md](../../en/errors/E0242.md)._

Un module owned (`.peras`) se compile en WebAssembly, où rien n’attend : il calcule et rend. Un module managed (`.apeiron`) se compile en JavaScript, pour ce qui parle au navigateur ([décision 0008](../decisions/0008-managed-mode.md)). Seul un module managed peut déclarer une fonction `async`, attendre une promesse avec `await`, écrire les types `number` et `Promise<T>`, ou importer avec `import` les fonctions d’un autre module. Dans un module managed, `await` est aussi refusé hors d’une fonction `async` : il attend une promesse, et la fonction qui l’utilise doit donc en rendre une elle-même.

## Exemple

```peras
export async fn total(xs: Array<f64>): Promise<f64> {
  return xs.reduce((a, x) => a + x, 0.0);
}
```

C’est un module owned : il ne peut pas attendre.

## Correction

Gardez le calcul dans le module owned, et attendez dans un module `.apeiron` qui l’importe :

```peras
export fn total(xs: Array<f64>): f64 {
  return xs.reduce((a, x) => a + x, 0.0);
}
```
