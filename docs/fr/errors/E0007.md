# E0007 : Caractère de contrôle bidirectionnel

_Version anglaise, qui fait foi : [../../en/errors/E0007.md](../../en/errors/E0007.md)._

Le source contient un caractère Unicode invisible qui change l'ordre d'affichage du texte.

Ces caractères (U+202A à U+202E, U+2066 à U+2069) peuvent faire paraître le code différent de ce qu'il compile : du code qui semble commenté s'exécute, et du code qui semble s'exécuter est un commentaire. C'est l'attaque [Trojan Source](https://trojansource.codes), CVE-2021-42574. Peras les refuse partout, chaînes et commentaires compris, car un relecteur ne peut pas les voir.

## Exemple

La ligne ci-dessous ressemble à un commentaire inoffensif dans un éditeur, mais les caractères de contrôle qu'elle contient changent ce qu'elle est réellement.

```text
/*<U+202E> } <U+2066>if (isAdmin)<U+2069> <U+2066> begin admins only */
```

## Correction

Supprime ces caractères. Quand un texte en a vraiment besoin dans une chaîne, écris-le sous forme d'échappement visible :

```peras
let label = "user\u{2067}";
```
