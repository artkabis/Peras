# E0006 : Opérateur d'égalité stricte

_Version anglaise, qui fait foi : [../../en/errors/E0006.md](../../en/errors/E0006.md)._

Les opérateurs JavaScript `===` et `!==` n'existent pas en Peras.

Peras ne convertit jamais les types implicitement : `==` et `!=` comparent donc déjà strictement, comme `===` et `!==` en JavaScript. Comparer des valeurs de types différents est une erreur de type, pas un `false` silencieux.

## Exemple

```peras
if (count === 0) { return; }
```

## Correction

```peras
if (count == 0) { return; }
```
