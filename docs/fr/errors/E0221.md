# E0221 : Opérateur invalide

_Version anglaise, qui fait foi : [../../en/errors/E0221.md](../../en/errors/E0221.md)._

Un opérateur est appliqué à un type qui ne le permet pas : de l’arithmétique sur un `bool`, `-` sur un entier non signé, `!` sur un nombre, `[]` sur autre chose qu’un tableau, `?` sur autre chose qu’une `Option`.

## Exemple

```peras
fn f(ready: bool, n: i32): bool {
  return !n || ready + 1;
}
```

## Correction

```peras
fn f(ready: bool, n: i32): bool {
  return n == 0 || ready;
}
```
