# E0104 : Symbole inattendu

_Version anglaise, qui fait foi : [../../en/errors/E0104.md](../../en/errors/E0104.md)._

Un symbole ne correspond pas à la construction en cours : un `:` manquant avant un type, une `,` manquante entre des arguments, ou un mot en trop. L’annotation indique ce qui était attendu.

## Exemple

```peras
fn area(width f32): f32 { return width * width; }
```

## Correction

```peras
fn area(width: f32): f32 { return width * width; }
```
