# E0202 : Déclaration en double

_Version anglaise, qui fait foi : [../../en/errors/E0202.md](../../en/errors/E0202.md)._

Le même nom est déclaré deux fois dans une même portée : deux variables d’un bloc, deux paramètres, deux champs d’une structure, ou deux déclarations d’un module (fonctions, structures et constantes du module partagent un même espace de noms).

## Exemple

```peras
struct Point {
  x: f64;
  x: f64;
}
```

## Correction

```peras
struct Point {
  x: f64;
  y: f64;
}
```
