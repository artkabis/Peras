# E0237 : Une interface utilisée comme un type

_Version anglaise, qui fait foi : [../../en/errors/E0237.md](../../en/errors/E0237.md)._

Une interface dit ce qu’un type sait faire, pas quel type a une valeur. Le code qui marche pour tout type qui implémente une interface prend un paramètre de type contraint par elle : il est compilé une fois par type avec lequel on l’appelle, et chaque appel va droit à la méthode de ce type, sans coût à l’exécution.

## Exemple

```peras
interface Shape {
  fn area(self): f64;
}

fn double(s: Shape): f64 {
  return s.area() * 2.0;
}
```

## Correction

```peras
interface Shape {
  fn area(self): f64;
}

fn double<T: Shape>(s: T): f64 {
  return s.area() * 2.0;
}
```
