# E0101 : Point-virgule manquant

_Version anglaise, qui fait foi : [../../en/errors/E0101.md](../../en/errors/E0101.md)._

Une instruction est complète mais ne se termine pas par `;`. Peras n’insère pas de point-virgule : en JavaScript, l’insertion automatique peut fusionner deux lignes sans prévenir, par exemple quand une ligne commence par `(` ou `[`.

## Exemple

```peras
let a = 1
let b = 2;
```

## Correction

```peras
let a = 1;
let b = 2;
```
