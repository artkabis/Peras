# E0117 : `break` ou `continue` hors d’une boucle

_Version anglaise, qui fait foi : [../../en/errors/E0117.md](../../en/errors/E0117.md)._

`break` et `continue` ne fonctionnent qu’à l’intérieur d’une boucle `for` ou `while` de la même fonction.

## Exemple

```peras
fn check(x: i32): void {
  if (x < 0) {
    break;
  }
}
```

## Correction

```peras
fn check(x: i32): void {
  if (x < 0) {
    return;
  }
}
```
