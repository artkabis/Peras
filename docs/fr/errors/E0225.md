# E0225 : `?` dans une fonction qui ne peut pas renvoyer tôt

_Version anglaise, qui fait foi : [../../en/errors/E0225.md](../../en/errors/E0225.md)._

`?` donne la valeur à l’intérieur d’une option ou d’un résultat, ou renvoie aussitôt ce qu’il ne peut pas donner : `None` pour une option, l’erreur pour un résultat. La fonction doit pouvoir renvoyer cela : une `Option` pour `?` sur une option, un `Result` avec le même type d’erreur pour `?` sur un résultat. Sinon, traitez le cas sur place, avec `match` ou `unwrapOr`.

## Exemple

```peras
fn half(n: i32): Option<i32> {
  if (n % 2 != 0) {
    return None;
  }
  return Some(n / 2);
}

export fn quarter(n: i32): i32 {
  const h = half(n)?;
  return h / 2;
}
```

## Correction

```peras
fn half(n: i32): Option<i32> {
  if (n % 2 != 0) {
    return None;
  }
  return Some(n / 2);
}

export fn quarter(n: i32): Option<i32> {
  const h = half(n)?;
  return Some(h / 2);
}
```
