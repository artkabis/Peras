# E0200 : Nom non défini

_Version anglaise, qui fait foi : [../../en/errors/E0200.md](../../en/errors/E0200.md)._

Un nom est utilisé sans être déclaré dans cette portée ou une portée englobante. Quand un nom déclaré est proche, la correction le propose.

## Exemple

```peras
fn total(xs: Array<i32>): i32 {
  let sum = 0;
  for (const x of xs) sum += x;
  return summ;
}
```

## Correction

```peras
fn total(xs: Array<i32>): i32 {
  let sum = 0;
  for (const x of xs) sum += x;
  return sum;
}
```
