# E0239 : Une valeur qu’un gabarit ne sait pas encore écrire

_Version anglaise, qui fait foi : [../../en/errors/E0239.md](../../en/errors/E0239.md)._

Un gabarit, `` `${count} items` ``, écrit chacune de ses valeurs en texte : une chaîne telle quelle, un entier ou un booléen comme l’écrit `toString()`. Les flottants, les structures et les tableaux ne s’écrivent pas encore. Les flottants en texte viennent ensuite : leur forme exacte la plus courte, celle que donne JavaScript, demande un algorithme à elle.

## Exemple

```peras
export fn label(price: f64): String {
  return `costs ${price}`;
}
```

## Correction

Mettez-y un entier, un booléen ou une chaîne :

```peras
export fn label(cents: i64): String {
  return `costs ${cents} cents`;
}
```
