# E0239 : Une valeur qu’un gabarit ne sait pas encore écrire

_Version anglaise, qui fait foi : [../../en/errors/E0239.md](../../en/errors/E0239.md)._

Un gabarit, `` `${count} items` ``, écrit chacune de ses valeurs en texte : une chaîne telle quelle, un nombre ou un booléen comme l’écrit `toString()`, comme le fait JavaScript. Une structure, un tableau ou une option n’a pas encore de texte à elle : quels champs, dans quel ordre et comment, c’est au programme de le dire.

## Exemple

```peras
struct Point {
  x: f64;
  y: f64;
}

export fn label(p: Point): String {
  return `at ${p}`;
}
```

## Correction

Mettez-y ses champs, une valeur chacun :

```peras
struct Point {
  x: f64;
  y: f64;
}

export fn label(p: Point): String {
  return `at (${p.x}, ${p.y})`;
}
```
