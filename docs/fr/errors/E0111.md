# E0111 : Imbrication trop profonde

_Version anglaise, qui fait foi : [../../en/errors/E0111.md](../../en/errors/E0111.md)._

Des expressions ou des types sont imbriqués sur plus de 128 niveaux. La limite protège le compilateur : sans elle, un fichier hostile ou généré pourrait épuiser sa pile et le faire planter.

## Exemple

```peras
let x = ((((((((((((((((((… 1 …))))))))))))))))));
```

## Correction

```peras
let inner = …;
let x = inner + 1;
```
