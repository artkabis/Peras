# E0900 : Pas encore pris en charge par la génération de code

_Version anglaise, qui fait foi : [../../en/errors/E0900.md](../../en/errors/E0900.md)._

Le programme est du Peras valide, accepté par toutes les vérifications, mais `perasc build` ne sait pas encore compiler l’une de ses constructions. Les codes `E0900` à `E0999` signalent des limites du compilateur, pas des erreurs du programme ; ils disparaissent au fur et à mesure que la génération de code s’étend.

Aujourd’hui, la génération de code traite les fonctions dont les paramètres, variables et résultats sont `i32`, `i64`, `f32`, `f64`, `bool`, ou des structures de ces types, avec l’arithmétique, les comparaisons, `if`, `while`, `for`, `break`, `continue`, les appels entre fonctions, les conversions numériques (`toI32()`, `toI64()`, `toF32()`, `toF64()`), `abs()`, `sqrt()`, `floor()`, `ceil()` et les opérations comme `wrappingAdd()`. Tableaux, chaînes, options, `for…of`, paramètres `inout` et constantes de module viennent ensuite.

## Exemple

```peras
export fn total(xs: Array<i32>): i32 {
  return xs.length;
}
```

## Correction

Réserve ce code à `perasc check` pour l’instant, ou limite le module compilé avec `perasc build` aux constructions prises en charge.

```peras
export fn total(a: i32, b: i32): i32 {
  return a + b;
}
```
