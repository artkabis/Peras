# E0246 : Une propriété qui ne peut qu’être lue

_Version anglaise, qui fait foi : [../../en/errors/E0246.md](../../en/errors/E0246.md)._

Certaines propriétés du navigateur sont fixées par le navigateur lui-même : le `kind` et la `key` d’un évènement, le `ok` et le `status` d’une réponse, le `body` d’une page. Une page les lit, et ne peut pas les changer. La [référence du navigateur](../reference/browser.md) dit quelles propriétés peuvent être affectées.

## Exemple

```apeiron
export fn rename(e: Event): void {
  e.kind = "click";
}
```

## Correction

Lisez-la dans une variable à vous :

```apeiron
export fn label(e: Event): String {
  let text = e.kind;
  text += " event";
  return text;
}
```
