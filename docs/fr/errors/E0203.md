# E0203 : Variable ou paramètre inutilisé

_Version anglaise, qui fait foi : [../../en/errors/E0203.md](../../en/errors/E0203.md)._

Une variable ou un paramètre n’est jamais lu. Affecter une variable n’est pas la lire : un compteur qu’on ne fait qu’incrémenter est lui aussi inutilisé. Un paramètre qui doit exister mais n’est volontairement pas utilisé, par exemple pour respecter une signature, se nomme avec un `_` initial.

## Exemple

```peras
fn area(width: f64, height: f64): f64 {
  let unused = width * 2.0;
  return width * width;
}
```

## Correction

```peras
fn area(width: f64, _height: f64): f64 {
  return width * width;
}
```
