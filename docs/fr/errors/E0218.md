# E0218 : Valeur de retour incorrecte

_Version anglaise, qui fait foi : [../../en/errors/E0218.md](../../en/errors/E0218.md)._

`return;` apparaît dans une fonction qui renvoie une valeur, ou `return valeur;` dans une fonction `void`. Une fonction renvoie exactement ce que dit son type de retour.

## Exemple

```peras
fn half(x: f64): f64 {
  if (x < 0.0) return;
  return x / 2.0;
}
```

## Correction

```peras
fn half(x: f64): f64 {
  if (x < 0.0) return 0.0;
  return x / 2.0;
}
```
