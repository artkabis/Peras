# E0118 : Marqueur optionnel `?:`

_Version anglaise, qui fait foi : [../../en/errors/E0118.md](../../en/errors/E0118.md)._

Un champ ou un paramètre est marqué optionnel avec `?:`. Peras n’a pas de `undefined` ni de `null` implicites : une valeur qui peut manquer a le type `Option<T>`, qui contient `Some(valeur)` ou `None`, et le compilateur oblige à traiter les deux cas.

## Exemple

```peras
struct User {
  name: String;
  email?: String;
}
```

## Correction

```peras
struct User {
  name: String;
  email: Option<String>;
}
```
