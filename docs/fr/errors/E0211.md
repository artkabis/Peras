# E0211 : Entier littéral à la place d’un flottant

_Version anglaise, qui fait foi : [../../en/errors/E0211.md](../../en/errors/E0211.md)._

Un entier littéral comme `1` est utilisé là où un flottant est attendu. Il ne devient jamais un flottant implicitement : le point décimal rend l’intention visible.

## Exemple

```peras
let gain: f32 = 1;
```

## Correction

```peras
let gain: f32 = 1.0;
```
