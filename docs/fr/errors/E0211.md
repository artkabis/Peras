# E0211 : Entier littéral à la place d’un flottant (retiré)

_Version anglaise, qui fait foi : [../../en/errors/E0211.md](../../en/errors/E0211.md)._

**Retiré par la [décision 0030](../decisions/0030-numeric-literals.md).** Un entier littéral utilisé là où un flottant est attendu est désormais ce flottant, comme en Swift et en Go : les lignes ci-dessous se construisent. Le code est gardé, comme chaque code, et n’est plus émis.

Il était émis quand un entier littéral comme `1` était utilisé là où un flottant était attendu, avec pour raison que le point décimal rendait l’intention visible. La décision 0029 a mesuré ce que cela coûtait : 35 des 45 erreurs rencontrées en écrivant le bassin à partir de son TypeScript.

## Exemple, qui se construit aujourd’hui

```peras
let gain: f32 = 1;
```

Une variable n’est toujours jamais convertie : `n * x`, `n` un `i32` et `x` un flottant, est refusé ([E0210](E0210.md)), avec la correction `n.toF64()`.
