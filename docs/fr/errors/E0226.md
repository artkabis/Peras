# E0226 : Une contrainte inconnue

_Version anglaise, qui fait foi : [../../en/errors/E0226.md](../../en/errors/E0226.md)._

Une contrainte dit ce que doivent savoir faire les types qu’un paramètre représente. Il y en a six : `Eq` pour `==` et `!=`, `Ord` pour les comparaisons, `Numeric` pour l’arithmétique sur entiers et flottants, `Integer` et `Float` pour une seule sorte de nombre, et `Copy` pour les valeurs copiées au lieu d’être déplacées. Les interfaces, prochaine étape de la feuille de route, ajouteront les vôtres.

## Exemple

```peras
fn larger<T: Ordered>(a: T, b: T): T {
  if (a > b) {
    return a;
  }
  return b;
}
```

## Correction

```peras
fn larger<T: Ord>(a: T, b: T): T {
  if (a > b) {
    return a;
  }
  return b;
}
```
