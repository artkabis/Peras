# E0222 : `match` incomplet

_Version anglaise, qui fait foi : [../../en/errors/E0222.md](../../en/errors/E0222.md)._

Un `match` doit traiter chaque valeur que peut prendre ce qu’il examine : chaque variante d’une énumération ou d’une option, `true` et `false`, et pour les nombres ou les chaînes un `_` final. Quand une variante est ajoutée à une énumération, chaque `match` qui l’oublie est signalé : c’est tout l’intérêt de l’exhaustivité.

## Exemple

```peras
enum Shape {
  Circle(f64),
  Rect(f64, f64),
  Empty,
}

export fn area(s: Shape): f64 {
  return match (s) {
    Circle(r) => 3.14159 * r * r,
    Rect(w, h) => w * h,
  };
}
```

## Correction

```peras
enum Shape {
  Circle(f64),
  Rect(f64, f64),
  Empty,
}

export fn area(s: Shape): f64 {
  return match (s) {
    Circle(r) => 3.14159 * r * r,
    Rect(w, h) => w * h,
    Empty => 0.0,
  };
}
```
