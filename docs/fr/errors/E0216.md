# E0216 : Mauvais nombre d’arguments de type

_Version anglaise, qui fait foi : [../../en/errors/E0216.md](../../en/errors/E0216.md)._

Un type ou une fonction prend autant d’arguments de type qu’il a de paramètres de type : un pour `Array` et `Option`, deux pour `Result`, le nombre déclaré pour une structure, une énumération ou une fonction [générique](../guide/generics.md), et aucun pour les autres types.

## Exemple

```peras
let xs: Array = [];
let n: i32<f32> = 1;
```

## Correction

```peras
let xs: Array<f32> = [];
let n: i32 = 1;
```
