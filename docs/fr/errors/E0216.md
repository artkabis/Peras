# E0216 : Mauvais nombre d’arguments de type

_Version anglaise, qui fait foi : [../../en/errors/E0216.md](../../en/errors/E0216.md)._

`Array` et `Option` prennent exactement un argument de type, et les autres types n’en prennent aucun.

## Exemple

```peras
let xs: Array = [];
let n: i32<f32> = 1;
```

## Correction

```peras
let xs: Array<f32> = [];
let n: i32 = 1;
```
