# E0215 : Champ ou méthode inconnu

_Version anglaise, qui fait foi : [../../en/errors/E0215.md](../../en/errors/E0215.md)._

Un champ ou une méthode n’existe pas sur le type. Les champs d’une structure viennent de sa déclaration ; les types intégrés ont un ensemble fixe de membres : `length` sur les tableaux et les chaînes, des conversions comme `toF64()` et `abs()` sur les nombres, `sqrt()` ou `sin()` sur les flottants, `push()` et `pop()` sur les tableaux, `isSome()` sur les options.

## Exemple

```peras
fn size(xs: Array<f32>): i32 {
  return xs.size;
}
```

## Correction

```peras
fn size(xs: Array<f32>): i32 {
  return xs.length;
}
```
