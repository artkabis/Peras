# E0112 : Const sans valeur

_Version anglaise, qui fait foi : [../../en/errors/E0112.md](../../en/errors/E0112.md)._

Un `const` est déclaré sans `= valeur`. Un `const` reçoit sa valeur une seule fois, là où il est déclaré, et ne change jamais.

## Exemple

```peras
const limit: i32;
```

## Correction

```peras
const limit: i32 = 64;
```
