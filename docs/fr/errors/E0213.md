# E0213 : Type inconnu

_Version anglaise, qui fait foi : [../../en/errors/E0213.md](../../en/errors/E0213.md)._

Un nom de type n’est ni intégré ni une structure déclarée dans le module. Les types intégrés sont les entiers (`i8` à `i64`, `u8` à `u64`), `f32`, `f64`, `bool`, `String`, `void`, `Array<T>` et `Option<T>`.

## Exemple

```peras
let ratio: float = 0.5;
let count: number = 1;
```

## Correction

```peras
let ratio: f64 = 0.5;
let count: i32 = 1;
```
