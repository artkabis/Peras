# E0201 : Masquage

_Version anglaise, qui fait foi : [../../en/errors/E0201.md](../../en/errors/E0201.md)._

Une déclaration reprend le nom d’une autre d’une portée englobante : un paramètre, une variable, une fonction ou une structure. Peras refuse le masquage, car avec deux variables de même nom il est facile de lire ou de modifier la mauvaise.

## Exemple

```peras
fn scale(value: f64): f64 {
  if (value > 1.0) {
    let value = 1.0;
    return value;
  }
  return value;
}
```

## Correction

```peras
fn scale(value: f64): f64 {
  if (value > 1.0) {
    let clamped = 1.0;
    return clamped;
  }
  return value;
}
```
