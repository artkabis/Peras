# E0003 : Commentaire de bloc non terminé

_Version anglaise, qui fait foi : [../../en/errors/E0003.md](../../en/errors/E0003.md)._

Un commentaire `/*` n'a pas de `*/` fermant.

Un commentaire de bloc court jusqu'au prochain `*/`. Sans lui, tout le reste du fichier est un commentaire, et le code qui suit disparaît sans bruit.

## Exemple

```peras
/* calcule le gain
fn gain(x: f32): f32 { return x * 2.0; }
```

## Correction

Ferme le commentaire là où il doit finir.

```peras
/* calcule le gain */
fn gain(x: f32): f32 { return x * 2.0; }
```

Les commentaires de bloc ne s'imbriquent pas : le premier `*/` ferme le commentaire.
