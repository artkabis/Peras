# E0205 : Modification impossible

_Version anglaise, qui fait foi : [../../en/errors/E0205.md](../../en/errors/E0205.md)._

Un `const`, une variable de `for…of` déclarée `const` ou un paramètre est modifié. Un `const` ne change jamais. Un paramètre est en lecture seule sauf s’il est déclaré `inout`, ce qui montre à chaque appelant que la fonction le modifie.

## Exemple

```peras
struct Buffer {
  samples: Array<f32>;
}

fn gain(buf: Buffer, factor: f32): void {
  buf.samples[0] = buf.samples[0] * factor;
}
```

## Correction

```peras
struct Buffer {
  samples: Array<f32>;
}

fn gain(buf: inout Buffer, factor: f32): void {
  buf.samples[0] = buf.samples[0] * factor;
}
```
