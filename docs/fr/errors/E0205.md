# E0205 : Modification impossible

_Version anglaise, qui fait foi : [../../en/errors/E0205.md](../../en/errors/E0205.md)._

Un `const`, une variable de `for…of` déclarée `const` ou un paramètre est modifié. Un `const` ne change jamais. Un paramètre est en lecture seule sauf s’il est déclaré `inout`, ce qui montre à chaque appelant que la fonction le modifie.

## Exemple

```peras
struct Buffer {
  samples: Array<f32>;
}

fn gain(buf: Buffer, factor: f32): void {
  buf.samples[0] = buf.samples[0] * factor;
}
```

## Correction

```peras
struct Buffer {
  samples: Array<f32>;
}

fn gain(buf: inout Buffer, factor: f32): void {
  buf.samples[0] = buf.samples[0] * factor;
}
```

## Une copie d’un élément

En TypeScript, `const p = ps[i]` nomme l’objet que tient le tableau, et modifier `p` modifie le tableau. En Peras, un élément est une valeur : `const p = ps[i]` en lit une copie. Déclarée avec `let`, la copie changerait et l’élément resterait tel quel, un programme qui se construit et calcule autre chose ; le correctif proposé ici n’est donc pas `let`, mais d’écrire dans l’élément lui-même ([constat F122](../findings.md)).

```peras error E0205
struct Particle {
  x: f64;
  life: i32;
}

export fn step(): i32 {
  let ps = [Particle(0.0, 2), Particle(1.0, 1)];
  for (let i = 0; i < ps.length; i++) {
    const p = ps[i];
    p.life -= 1;
  }
  return ps[0].life;
}
```

```peras build
struct Particle {
  x: f64;
  life: i32;
}

export fn step(): i32 {
  let ps = [Particle(0.0, 2), Particle(1.0, 1)];
  for (let i = 0; i < ps.length; i++) {
    ps[i].life -= 1;
  }
  return ps[0].life;
}
```

Le `get` d’une table donne aussi une copie : pour changer une valeur tenue par une table, lis-la, change-la et remets-la, `let list = m.get(k).unwrapOr([]); list.push(i); m.set(k, list);`.
