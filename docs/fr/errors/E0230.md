# E0230 : Une fonction générique exportée

_Version anglaise, qui fait foi : [../../en/errors/E0230.md](../../en/errors/E0230.md)._

Le code générique est compilé une fois pour chaque jeu d’arguments de type que le module utilise. JavaScript peut appeler une fonction exportée avec n’importe quelle valeur : il n’y a donc pas de copie unique à exporter. Exportez une fonction non générique, et appelez depuis elle la fonction générique avec les types voulus.

## Exemple

```peras
export fn larger<T: Ord>(a: T, b: T): T {
  if (a > b) {
    return a;
  }
  return b;
}
```

## Correction

```peras
fn larger<T: Ord>(a: T, b: T): T {
  if (a > b) {
    return a;
  }
  return b;
}

export fn largerInt(a: i32, b: i32): i32 {
  return larger(a, b);
}
```
