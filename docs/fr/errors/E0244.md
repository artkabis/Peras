# E0244 : Un import impossible

_Version anglaise, qui fait foi : [../../en/errors/E0244.md](../../en/errors/E0244.md)._

Un module managed importe des fonctions de modules owned (`.peras`) par leur chemin relatif, et les appelle à travers des conversions vérifiées ([décision 0008](../decisions/0008-managed-mode.md)). L’import est refusé quand le fichier n’est pas un module owned qui se compile, quand le nom n’est pas une de ses fonctions exportées, ou quand la fonction prend ou rend une valeur qui ne passe pas encore : les nombres, les booléens, les chaînes, et les tableaux, options, résultats, tables et ensembles de ceux-ci passent ; une structure ou une énumération est le type propre de l’autre module, et ne passe pas encore.

## Exemple

Avec `./stats.peras` qui exporte `fn mean(xs: Array<f64>): f64` :

```apeiron
import { average } from "./stats.peras";

export fn score(xs: Array<number>): number {
  return average(xs);
}
```

`average` n’est pas une fonction de `./stats.peras`.

## Correction

Importez la fonction par son nom :

```apeiron
import { mean } from "./stats.peras";

export fn score(xs: Array<number>): number {
  return mean(xs);
}
```
