# E0244 : Un import impossible

_Version anglaise, qui fait foi : [../../en/errors/E0244.md](../../en/errors/E0244.md)._

Un module managed importe des fonctions, des structures et des énumérations de modules owned (`.peras`) par leur chemin relatif, et appelle les fonctions à travers des conversions vérifiées ([décision 0008](../decisions/0008-managed-mode.md), [décision 0021](../decisions/0021-phases-4-and-5.md)). L’import est refusé quand le fichier n’est pas un module owned qui se compile, quand le nom n’est pas une de ses fonctions, structures ou énumérations exportées, quand une fonction prend ou rend une valeur qui ne passe pas, ou quand ce module déclare un type du même nom qu’un type qu’il importe. Les nombres, les booléens, les chaînes, les structures et énumérations non génériques du module owned, et les tableaux, options, résultats, tables et ensembles de ceux-ci passent ; une structure générique, une fonction ou un type du navigateur ne passent pas.

## Exemple

Avec `./stats.peras` qui exporte `fn mean(xs: Array<f64>): f64` :

```apeiron
import { average } from "./stats.peras";

export fn score(xs: Array<number>): number {
  return average(xs);
}
```

`average` n’est pas une fonction de `./stats.peras`.

## Correction

Importez la fonction par son nom :

```apeiron
import { mean } from "./stats.peras";

export fn score(xs: Array<number>): number {
  return mean(xs);
}
```
