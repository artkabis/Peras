# E0229 : Un argument de type que rien ne détermine

_Version anglaise, qui fait foi : [../../en/errors/E0229.md](../../en/errors/E0229.md)._

Les arguments de type d’une fonction générique viennent de ses arguments, ou du type que l’appel doit avoir. `empty` ne prend pas d’argument, et `const xs = empty();` ne dit pas ce que contient le tableau : donnez un type à la variable.

## Exemple

```peras
fn empty<T>(): Array<T> {
  return [];
}

export fn count(): i32 {
  const xs = empty();
  return xs.length;
}
```

## Correction

```peras
fn empty<T>(): Array<T> {
  return [];
}

export fn count(): i32 {
  const xs: Array<i32> = empty();
  return xs.length;
}
```
