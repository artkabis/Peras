# E0209 : Déplacer ce qui n’est qu’emprunté

_Version anglaise, qui fait foi : [../../en/errors/E0209.md](../../en/errors/E0209.md)._

Une valeur est déplacée par ce qui ne la possède pas. Un paramètre qui n’est pas `sink` emprunte la valeur de l’appelant ; un champ appartient à sa structure, un élément à son tableau, une valeur du niveau du module au module. Déplace une copie, faite avec `.copy()`, ou déclare le paramètre `sink`.

## Exemple

```peras
export fn keep(xs: Array<i32>): Array<i32> {
  return xs;
}
```

## Correction

```peras
export fn keep(xs: sink Array<i32>): Array<i32> {
  return xs;
}
```
