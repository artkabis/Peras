# E0004 : Séquence d'échappement invalide

_Version anglaise, qui fait foi : [../../en/errors/E0004.md](../../en/errors/E0004.md)._

Une chaîne contient un `\` suivi de quelque chose qui n'est pas une séquence d'échappement.

Les chaînes n'acceptent que ces échappements :

| Échappement      | Signification                                        |
| ---------------- | ---------------------------------------------------- |
| `\n`, `\r`, `\t` | saut de ligne, retour chariot, tabulation            |
| `\0`             | caractère nul                                        |
| `\\`, `\'`, `\"` | barre oblique inverse, guillemets                    |
| `\u{1F600}`      | valeur scalaire Unicode, 1 à 6 chiffres hexadécimaux |

La valeur doit être comprise entre `\u{0}` et `\u{10FFFF}`, hors substituts `\u{D800}` à `\u{DFFF}`.

## Exemple

```peras
let pattern = "\d+";
let e = "\u00e9";
```

## Correction

Pour écrire une barre oblique inverse, double-la. Les formes JavaScript `\u00e9` et `\x41` s'écrivent avec des accolades.

```peras
let pattern = "\\d+";
let e = "\u{00e9}";
```
