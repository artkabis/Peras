# E0109 : Opérateur bit à bit mélangé à une comparaison

_Version anglaise, qui fait foi : [../../en/errors/E0109.md](../../en/errors/E0109.md)._

Un opérateur bit à bit (`&`, `|`, `^`) et une comparaison apparaissent ensemble sans parenthèses. JavaScript lit `flags & 1 == 0` comme `flags & (1 == 0)`, car les opérateurs bit à bit sont moins prioritaires que les comparaisons. Peras exige les parenthèses, et la correction les place là où elles sont généralement voulues.

## Exemple

```peras
if (flags & 1 == 0) { … }
```

## Correction

```peras
if ((flags & 1) == 0) { … }
```
