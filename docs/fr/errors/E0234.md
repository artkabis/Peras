# E0234 : Des méthodes pour un type qui ne peut pas en avoir

_Version anglaise, qui fait foi : [../../en/errors/E0234.md](../../en/errors/E0234.md)._

Un `impl` donne des méthodes à une structure ou une énumération déclarée dans le module. Les nombres, les chaînes, les tableaux et les options ont les méthodes prédéfinies de la [référence des méthodes](../reference/methods.md) ; pour donner les vôtres à l’un d’eux, enveloppez-le dans une structure : cela ne coûte rien, une structure étant gardée comme ses champs.

## Exemple

```peras
impl f64 {
  fn double(self): f64 {
    return self * 2.0;
  }
}
```

## Correction

```peras
struct Meters {
  value: f64;
}

impl Meters {
  fn double(self): Meters {
    return Meters(self.value * 2.0);
  }
}

export fn twice(m: f64): f64 {
  return Meters(m).double().value;
}
```
