# E0001 : Caractère invalide

_Version anglaise, qui fait foi : [../../en/errors/E0001.md](../../en/errors/E0001.md)._

Un caractère sans signification en Peras apparaît hors d'une chaîne ou d'un commentaire.

Le code Peras n'utilise que des lettres ASCII, des chiffres, `_`, des espaces et les opérateurs du langage. Les caractères collés depuis un traitement de texte en sont une cause fréquente : guillemets typographiques, signe moins `−`, espace insécable. Les caractères invalides adjacents sont signalés ensemble.

## Exemple

```peras
let total = price × 2;
let café = 1;
```

## Correction

Quand le caractère ressemble à un caractère ASCII, la correction le remplace : `×` devient `*`, `“` devient `"`, `−` devient `-`.

```peras
let total = price * 2;
let cafe = 1;
```

Les noms sont en ASCII uniquement, ce qui exclut aussi des noms d'apparence identique mais écrits avec des caractères différents. Le texte, dans n'importe quelle langue, va dans des chaînes : `"café"`. Les gabarits de chaîne (`` `…` ``) ne sont pas encore pris en charge : concatène les chaînes avec `+`.
