# Documentation de Peras

L'anglais fait foi ; chaque page a sa traduction française sous `docs/fr/`, au même chemin.

- [Spec du langage](spec.md) : piliers, nom et extensions, types, modèle mémoire, pile et tas, rasterisation, diagnostics, architecture, roadmap du MVP.
- [Plan de démarrage du compilateur](kickoff-plan.md) : organisation du dépôt, choix techniques, contrôles qualité, les deux premières semaines, règles de travail.
- `errors/` : une page par code d'erreur du compilateur, affichée par `perasc explain <code>`.
- `decisions/` : décisions d’architecture, avec leur statut et les mesures qui les fondent.
